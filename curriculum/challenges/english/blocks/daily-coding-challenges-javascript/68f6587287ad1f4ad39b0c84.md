# --description--

Given two positive integers, `width` and `height`, create a grid with `width` columns and `height` rows. Count all rectangles made from one or more cells of the grid.

Squares count as rectangles. Include each single cell and any larger squares.

Rectangles can overlap. Count rectangles in different positions separately, even if they are the same size.

For example, a grid with a `height` of 1 and `width` of 3 contains 6 rectangles: three single cells, two pairs of neighboring cells, and one rectangle containing all three cells.

```js
function countRectangles(width, height) {
  let count = 0;

  for (let w = 1; w <= width; w++) {
    for (let h = 1; h <= height; h++) {
      count += (width - w + 1) * (height - h + 1);
    }
  }

  return count;
}
```
