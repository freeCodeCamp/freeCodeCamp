# --description--

You need one of those rows for every row up to `row`. Writing `[[0] * (col + 1)] * (row + 1)` would repeat the same row object, so changing one row would change them all. A list comprehension avoids this by building a fresh row on each iteration.

Update the value of `table` to `[[0] * (col + 1) for _ in range(row + 1)]`.
