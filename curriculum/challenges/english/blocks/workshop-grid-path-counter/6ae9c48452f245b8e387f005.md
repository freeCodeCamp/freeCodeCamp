# --description--

When your function starts calling itself, it will look above the top row and to the left of the first column, which makes `row` or `col` equal to `-1`. `grid[-1]` doesn't raise an error. Instead, it quietly returns the last row.

To stop the function from counting squares outside the grid, add `row < 0 or col < 0` to the start of the condition of your first `if` statement. Python evaluates `or` from left to right and stops at the first `True` value, so it never reaches `grid[row][col]` with a negative index.
