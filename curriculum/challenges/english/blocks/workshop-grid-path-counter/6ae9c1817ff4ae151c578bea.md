# --description--

To count the paths to a square, your function would have to call itself on the square above and the square to the left.

A function that calls itself is recursive. It needs a base case, that is, a point where it returns an answer without calling itself again. Otherwise, it keeps calling itself until Python raises a `RecursionError`.

Your base case is the starting square at row `0`, column `0`, because there's exactly one path to it.

To add it, replace `pass` with an `if` statement that returns `1` when `row` is `0` and `col` is `0`.
