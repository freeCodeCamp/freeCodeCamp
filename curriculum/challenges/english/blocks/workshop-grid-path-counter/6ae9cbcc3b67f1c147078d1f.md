# --description--

At the top of the `count_paths_top_down` function, add an `if` statement with the condition `memo is None`. Inside it, set `memo` to an empty dictionary.

You might wonder why `memo` doesn't default to `{}`. That's because Python creates a default value only once, when the function is defined, and every call shares that same dictionary. If `memo` defaulted to `{}`, results saved for `warehouse` would leak into the call for `open_floor` and give wrong answers. Starting with `None` and creating a new dictionary on each top-level call keeps them separate.
