Notice that `each_pays` was printed as `62.1` instead of `62.10` that you'd usually get with an f-string. That's because `round()` returns a float, and Python doesn't print trailing zeros for floats.

This is where f-string formatting helps. `round()` gives you a number you can keep calculating with, and `:.2f` controls how that number is displayed.
