# --description--

Let's learn how to search for files and folders on Windows and macOS.

We'll start with Windows. You can search from the Taskbar or from File Explorer.

To search from the Taskbar, type the name of the file or folder that you are looking for. You can also search for keywords. You'll see results from across your PC and OneDrive.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-1.png" alt="Windows 11 taskbar with Start button, search bar, Task View, and Chrome icon">

If you only want to see documents, you can click on the "Documents" tab. You also have tabs for apps and web results.

Another option is to use the search box in File Explorer. You'll find it at the top right of the File Explorer window, where you may see placeholder text such as "Search Documents."

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-2.png" alt="Windows File Explorer with the Search Documents box highlighted at the top right">

You have three options for defining the scope of the search:

- You can search from Home to quickly find files from your PC and the cloud.

- You can search from a specific folder to find files stored inside it.

- You can search from This PC to search across your computer. This search may take longer because it covers a broader range of locations.

This is how you can search for files and folders on Windows. Now let's see how you can do this on macOS.

First, you can use Spotlight, a tool that helps you find files on your Mac. To open Spotlight, go to the menu bar at the top right of your screen and look for the magnifying glass icon.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-3.png" alt="macOS menu bar featuring system icons, including the magnifying glass Spotlight icon">

If you don't see this icon in the menu bar, you can add it through your system settings.

On macOS Ventura (version 13) through macOS Sequoia (version 15), open System Settings, select "Control Center" in the sidebar, and scroll down to the "Menu Bar Only" section. Find "Spotlight" and configure its menu bar display. On macOS Tahoe (version 26), you can manage the Spotlight icon through the Menu Bar settings.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-4.png" alt="macOS Control Center settings window showing Spotlight set to Show in Menu Bar">

You can also use a keyboard shortcut to open Spotlight: <kbd>Command</kbd> + <kbd>Spacebar</kbd>.

When you open Spotlight, you'll see the Spotlight Search field, where you can search for any file or folder by typing its name.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-5.png" alt="macOS Spotlight Search bar open on screen">

When you start typing, you'll see results grouped by category, including suggestions, folders, presentations, photos, documents, and related searches.

You can also expand a specific category by clicking on "Show More."

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-6.png" alt="macOS Spotlight Search displaying search results for freeCodeCamp">

Another way to search for files that you have recently opened is to open Finder by clicking on the Finder icon in the Dock.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-7.png" alt="macOS Dock featuring the blue Finder icon alongside Launchpad and Google Chrome icons">

Then, go to "Recents" in the Finder sidebar.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-8.png" alt="macOS Finder sidebar with the Recents option highlighted under Favorites">

There, you'll find files that you've recently viewed.

This is how you can search for files and folders on macOS. With these search tools, you can optimize your workflow and find the files and folders you need quickly.
