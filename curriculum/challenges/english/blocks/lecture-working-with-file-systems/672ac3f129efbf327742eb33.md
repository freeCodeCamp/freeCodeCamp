# --description--

Let's learn how to search for files and folders on Windows and macOS.

We'll start with Windows. You can search from the Taskbar or from the File Explorer.

To search from the Taskbar, write the name of the file or folder that you are looking for. You can also search for keywords. You'll see results from across your PC and OneDrive.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-1.png" alt="Windows 11 taskbar with Start button, search bar, Task View, and Chrome icon">

If you only want to see documents, you can click on the "Documents" tab. You also have tabs for apps and web results.

Another alternative is to use the Search File Explorer. You will find it at the top right of the Explorer window, where you can see "Search Documents."

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-2.png" alt="Windows File Explorer with the Search Documents box highlighted on the top right">

You have three options to define the scope of the search:

- You can search from Home to find files from your PC and from the cloud quickly.

- You can search from a folder to find files stored inside it.

- You can search from This PC for a slow but in-depth search.

This is how you can search for files and folders on Windows. Now let's see how you can do this on macOS.

First, you can use Spotlight, a tool that helps you find files on your Mac. To open Spotlight, go to your menu bar at the top right and find the magnifying glass.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-3.png" alt="macOS menu bar featuring system icons including the magnifying glass Spotlight icon">

If you don't see this icon on the menu bar, you can add it in the Control Center settings.

Go to your settings, filter by "Control Center", click on this option and then scroll down until you find the "Spotlight" option.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-4.png" alt="macOS Control Center settings window showing Spotlight set to Show in Menu Bar">

You can also use a keyboard shortcut to open Spotlight: <kbd>Command</kbd> + <kbd>Spacebar</kbd>.

When you open Spotlight, you'll see the Spotlight Search, where you can search for any file or folder by typing its name.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-5.png" alt="macOS Spotlight Search bar open on screen">

When you start typing, you'll see the results grouped by category, including suggestions, folders, presentations, photos, documents, and related searches.

You can also expand a specific category by clicking on "Show More."

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-6.png" alt="macOS Spotlight Search displaying search results for freeCodeCamp">

Another way to search for files that you have recently opened is to open Finder by clicking on the Finder icon in the Dock.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-7.png" alt="macOS Dock featuring the blue Finder icon alongside Launchpad and Google Chrome icons">

Then, go to "Recents" in the Finder sidebar.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-8.png" alt="macOS Finder sidebar with the Recents option highlighted under Favorites">

And there, you'll find all the files that you've recently viewed.

This is how you can search for files and folders on macOS. With these search tools, you can optimize your workflow and find the files and folders you need very quickly.
