# --description--

To open and close the `sub-menu`, your `Navbar` component needs to remember whether the `sub-menu` is currently open. Data that a component remembers, and that can change over time, is called state. Whenever the state changes, React re-renders the component so the page shows the new value.

You will learn a lot more about state in upcoming lessons. For now, you only need to know that you can add state to a functional component with the `useState` hook. Hooks are special functions that let you use React features in your components. Because React is loaded with a `script` element in this workshop, you can access the hook as `React.useState`:

```jsx
const [count, setCount] = React.useState(0);
```

`React.useState` takes the initial value of the state as its argument and returns an array with two items, which are unpacked here with array destructuring:

- `count` is the state variable, which holds the current value.
- `setCount` is the setter function, which you call to update the state.

By convention, the setter function has the same name as the state variable, with a `set` prefix. Also, hooks must be called at the top level of your component, before the `return` statement.

Inside the `Navbar` component, use `React.useState` to create a state variable called `isOpen` and a setter function called `setIsOpen`. Since the `sub-menu` should start out closed, give it an initial value of `false`.
