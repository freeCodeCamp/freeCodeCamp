# --description--

The last thing to do is update the `isOpen` state when the `Apps` button is clicked.

In React, you respond to events by passing a function to an event attribute on an element. These attributes are written in camelCase, so a click is handled with `onClick`:

```jsx
<button onClick={() => setCount(count + 1)}>Add one</button>
```

Notice that `onClick` receives a function. React calls that function every time the button is clicked. Calling the setter function with a new value updates the state, and React then re-renders the component with that new value.

To toggle a Boolean state between `true` and `false`, you can pass the opposite of its current value to the setter function by using the logical NOT (`!`) operator.

Add an `onClick` attribute to the `button` element. Give it an arrow function that calls `setIsOpen` with the opposite of `isOpen`.

With that, your `Navbar` component is complete! Click the `Apps` button to open and close the `sub-menu`.

```js
  await new Promise(resolve => setTimeout(resolve, 0));
}
```

