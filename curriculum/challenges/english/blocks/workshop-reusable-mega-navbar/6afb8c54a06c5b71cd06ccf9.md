# --description--

The last thing to do is update the state when the `Apps` button is clicked.

In React, you handle events by passing a function to an event attribute, written in camelCase, like `onClick`:

```jsx
<button onClick={() => console.log("Clicked!")}>Click me</button>
```

Note that you pass a function, not the result of calling one.

To toggle a Boolean value, you can use the logical NOT operator (`!`), which turns `true` into `false` and `false` into `true`.

Add an `onClick` attribute to the `Apps` button. Its value should be an arrow function that calls `setIsOpen` with the opposite of `isOpen`.

With that, your `Navbar` component is complete! Click the `Apps` button to open and close the sub-menu.

```js
const button = document.querySelector('button');
const subMenu = document.querySelector('.sub-menu');
assert.equal(button?.getAttribute('aria-expanded'), 'false');

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
assert.equal(button?.getAttribute('aria-expanded'), 'true');

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
assert.equal(button?.getAttribute('aria-expanded'), 'false');
```

Clicking the `Apps` button should add and remove the `sub-menu--open` class on the `sub-menu`.

```js
const button = document.querySelector('button');
const subMenu = document.querySelector('.sub-menu');
assert.isFalse(subMenu?.classList.contains('sub-menu--open'));

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
assert.isTrue(subMenu?.classList.contains('sub-menu--open'));

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
assert.isFalse(subMenu?.classList.contains('sub-menu--open'));
```
