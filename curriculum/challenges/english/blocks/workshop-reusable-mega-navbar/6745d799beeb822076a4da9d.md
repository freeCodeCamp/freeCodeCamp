# --description--

React's `useState` hook lets a component remember a value between renders. It returns an array with the current state and a function to update it. Here is the basic syntax:

```js
const [state, setState] = React.useState(initialValue);
```

At the beginning of your `Navbar` component, create an `isOpen` state initialized to `false`, along with its `setIsOpen` function.

Then, inside your third `li` element, create a `button` element. Set its `aria-expanded` attribute to the string `"true"` when `isOpen` is true, and to the string `"false"` otherwise. Also, set the text of the `button` to `Apps`.

The `aria-expanded` attribute will communicate to screen reader users that the button triggers an expandable submenu.
