# --description--

Now you can use `isOpen` in your JSX. The `aria-expanded` attribute tells assistive technologies, like screen readers, whether the content controlled by a button is open.

In JSX, you can use a JavaScript expression as an attribute value by wrapping it in curly braces. The ternary operator is a common way to pick between two values:

```jsx
<p className={isActive ? "active" : "inactive"}>Status</p>
```

Change the `aria-expanded` value of the `button` to an expression that evaluates to `"true"` when `isOpen` is `true`, and to `"false"` otherwise.
