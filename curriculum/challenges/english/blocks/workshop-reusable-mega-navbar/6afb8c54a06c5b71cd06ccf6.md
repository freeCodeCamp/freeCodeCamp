# --description--

To open and close the sub-menu, the `Navbar` component needs to remember whether the sub-menu is open. Data that a component remembers between renders, and that can change over time, is called **state**.

You can add state to a component with the `useState` hook. In this workshop, React is loaded with a `script` element, so you access the hook as `React.useState`.

`useState` takes the initial value of the state and returns an array with two items: the current value, and a function to update it. You can use array destructuring to give them names:

```jsx
const [count, setCount] = React.useState(0);
```

The convention is to name the pair `something` and `setSomething`.

At the top of the `Navbar` component, before the `return` statement, create a state variable named `isOpen` and a set function named `setIsOpen`. Give the state an initial value of `false`, since the sub-menu should start closed.
