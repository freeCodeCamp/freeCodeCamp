# --description--

The last rule is about the 3x3 box that contains the cell. To check the box, you need to know the row and the column where it starts.

Using floor division to divide `row` by `3` gives the position of the box, from `0` to `2`. Multiplying that by `3` gives the index of the first row of the box. For example, `(5 // 3) * 3` is `3`, so row `5` belongs to the box that starts at row `3`. The same goes for columns.

Create a variable named `box_row` and assign it `(row // 3) * 3`. Then, create a variable named `box_col` and assign it `(col // 3) * 3`.
