# --description--

The numbers can't be placed randomly. In Sudoku, every row, every column, and every 3x3 box of the grid must contain each number from `1` to `9` exactly once.

Before placing a number in a cell, the solver needs to check that the number doesn't break any of these rules. This lets it reject a bad choice right away, instead of discovering the problem later.

Below your `find_empty_cell` function, define a function named `is_valid` with four parameters: `board`, `row`, `col`, and `num`. Inside it, return `False` if `num` is already in `board[row]`.
