# --description--

The board would be easier to read without brackets and commas, and with empty cells that stand out.

Since `0` is falsy, the conditional expression `str(num) if num else '*'` turns an empty cell into `*` and any other number into a string.

Replace `print(row)` with a call to `print` that prints the values of `str(num) if num else '*' for num in row` joined by a space.
