# --description--

In the previous lesson, you learned about backtracking. In this workshop, you'll use it to build a Sudoku solver.

Sudoku is a puzzle played on a 9x9 grid. Some cells start with a number, and the goal is to fill in the empty cells with numbers from `1` to `9`.

You can represent the grid as a list of lists, where each inner list is a row and `0` represents an empty cell.

Create a variable named `puzzle` and assign it the following list:

```py
[
    [0, 0, 2, 0, 0, 8, 0, 0, 0],
    [0, 0, 0, 0, 0, 3, 7, 6, 2],
    [4, 3, 0, 0, 0, 0, 8, 0, 0],
    [0, 5, 0, 0, 3, 0, 0, 9, 0],
    [0, 4, 0, 0, 0, 0, 0, 2, 6],
    [0, 0, 0, 4, 6, 7, 0, 0, 0],
    [0, 8, 6, 7, 0, 4, 0, 0, 0],
    [0, 0, 0, 5, 1, 9, 0, 0, 8],
    [1, 7, 0, 0, 0, 6, 0, 0, 5]
]
```
