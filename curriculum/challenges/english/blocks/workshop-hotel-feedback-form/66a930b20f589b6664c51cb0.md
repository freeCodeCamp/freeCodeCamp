# --description--

The `type` attribute tells the browser what kind of data an `input` should accept. Some common values for the `type` attribute are:

- `text`: a single-line text field
- `email`: a text field that checks that the user enters a valid email address
- `number`: a field for numbers
- `radio` and `checkbox`: options the user can select

Here is an example of a text input:

```html
<input type="text">
```

For the existing `input` element, add a `type` attribute set to `"text"`.

Also give the `input` element an `id` attribute with the value of `"full-name"`. This matches the `for` attribute on your `label` element, which connects the two together.

When a user provides their full name, the `input` will accept plain text.
