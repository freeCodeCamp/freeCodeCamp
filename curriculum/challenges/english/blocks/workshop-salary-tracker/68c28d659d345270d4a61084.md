# --description--

The `__repr__` method is a special method that is supposed to return a string representation of the object that can be used to instantiate it.

For example, the `__repr__` method of `Employee('Charlie', 'developer')` should return the string `Employee('Charlie', 'developer')`, which is the same string used to create the object.

If you have quotes around each value, the result breaks when a value contains a quote. For an employee named `O'Reilly` with a level of `junior`, you would get `Employee('O'Reilly', 'junior')`, which is not valid because the apostrophe closes the string early.

Python's built-in `repr()` function returns a string representation of a value. For strings, it adds the quotes and escapes any characters that need it:

```py
print(repr('Charlie')) # 'Charlie'
print(repr("O'Reilly")) # "O'Reilly"
print('C:\\new', repr('C:\\new')) # C:\new 'C:\\new'
```

Inside an f-string, you can add `!r` after an expression to apply `repr()` to it:

```py
name = "O'Reilly"
print(f'Name: {name!r}')  # Name: "O'Reilly"
```

Give your `Employee` class a `__repr__` method with a `self` parameter. Make it return a string that can be used to instantiate the object, using `!r` on `self.name` and `self.level` so that any quotes or backslashes are preserved.
