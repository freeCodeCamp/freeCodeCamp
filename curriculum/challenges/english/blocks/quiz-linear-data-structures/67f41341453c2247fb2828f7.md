### --question--

#### --text--

What is the key difference between dynamic arrays and static arrays?

#### --distractors--

Dynamic arrays store values of different types; static arrays cannot.

---

Static arrays allow access by index; dynamic arrays must be traversed from the first element.

---

Dynamic arrays are faster than static arrays for every operation.

#### --answer--

Dynamic arrays can grow or shrink by resizing; static arrays have a fixed size.

### --question--

#### --text--

Why does accessing an element of a static array by index take `O(1)` time?

#### --distractors--

The array is sorted, so the element can be found with a binary search.

---

Each element stores a reference to the element at the next index.

---

The array is traversed from the first element until the index is reached.

#### --answer--

Elements are stored in adjacent memory locations, so the location of any element can be calculated from the first element and the index.

### --question--

#### --text--

What will be printed after running the following code?

```py
class LinkedList:
    class Node:
        def __init__(self, element):
            self.element = element
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None

    def add_to_start(self, element):
        node = self.Node(element)
        node.next = self.head
        self.head = node
        self.length += 1

my_list = LinkedList()

my_list.add_to_start('B')
my_list.add_to_start('C')
```

---

---

### --question--

#### --text--

What is the main tradeoff of using a doubly linked list instead of a singly linked list?

#### --distractors--

Doubly linked lists must be traversed to the end to add a node there, unlike singly linked lists.

---

Inserting a node at the start of a doubly linked list takes `O(n)` time.

---

Accessing a node by index takes `O(n)` time in a doubly linked list, but `O(1)` in a singly linked list.

#### --answer--

Doubly linked lists require more memory because each node stores two references instead of one.
