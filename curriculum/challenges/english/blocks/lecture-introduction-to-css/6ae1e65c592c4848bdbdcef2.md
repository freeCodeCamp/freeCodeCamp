# --interactive--

The `text-decoration` property lets you add decorative lines to text.

With its initial value of `none`, it is commonly used to remove the default underline that browsers add to links when customization of such links is needed.

```css
a {
  text-decoration: none;
}
```

Although commonly used for links, `text-decoration` can also decorate other text.

## Other Values of the `text-decoration` Property

Apart from `none`, other values of the `text-decoration` property are:

- `underline`
- `overline`
- `line-through`

As the names of the values imply, `underline` adds a line under the text, `overline` adds a line over the text, and `line-through` adds that line right in the middle of the text, like canceling the text.

## There's More to the `text-decoration` Property

The `text-decoration` property is actually a shorthand property that combines the following properties:

- `text-decoration-line`: `none`, `underline`, `overline`, and `line-through`
- `text-decoration-color`: The color of the line.
- `text-decoration-style`: `solid`, `double`, `dotted`, `dashed`, or `wavy`.
- `text-decoration-thickness`: The thickness of the line.

For example, this adds a red squiggly line to a paragraph:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>This is an error</p>
```

```css
p {
  text-decoration: underline wavy red 2px;
}
```

:::

And this adds a double green overline to a paragraph:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>There's a double overline on this text</p>
```

```css
p {
  text-decoration: overline double green 2px;
}
```

:::

You can also combine line types if you want:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<h2>This subheading has both an underline and overline</h2>
```

```css
h2 {
  text-decoration: underline overline;
}
```

:::
