# --description--

If `key` is neither less than nor greater than `node.key`, you've found the node to delete. How you delete it depends on its children.

If the node has no left child, its right child can take its place. This also covers nodes with no children: in that case, `node.right` is `None` too, so the node is replaced with `None`.

Add an `else` clause to your second `if` statement. Inside it, add an `if` statement that checks if `node.left` is `None`, and return `node.right` from it.
