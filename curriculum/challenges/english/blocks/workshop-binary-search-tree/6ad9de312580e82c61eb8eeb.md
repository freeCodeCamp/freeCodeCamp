# --description--

To insert a value, you start from the root and go left if the value is smaller than the node's value, or right if it's greater, until you reach an empty spot. Since each subtree is a binary search tree too, you can do this with recursion.

Inside the `BinarySearchTree` class, create a method named `_insert` with three parameters: `self`, `node`, and `key`. The leading underscore marks it as a helper for internal use.

Inside it, add an `if` statement that checks if `key` is less than `node.key`. Inside the `if`, call `self._insert` with `node.left` and `key`, and assign the result to `node.left`. This inserts the value into the left subtree and keeps the updated subtree attached to the current node.
