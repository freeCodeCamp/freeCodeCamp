# --description--

When the node has two children, you need to replace its value with another one while keeping the tree ordered. The right choice is its inorder successor: the value that comes right after it in an inorder traversal.

The inorder successor is the smallest value in the node's right subtree, and you can find it by going left from the right child as far as possible.

Inside the `BinarySearchTree` class, create a method named `_min_value` with two parameters, `self` and `node`. Inside it, use a `while` loop to assign `node.left` to `node` as long as `node.left` is not `None`. After the loop, return `node.key`.
