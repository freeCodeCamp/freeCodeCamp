## What Is a Tuple?

A tuple is a Python data type used to create an ordered sequence of values. Tuples can contain a mixed set of data types like this:

```py
developer = ('Alice', 34, 'Rust Developer')
```

The commas create the tuple, so parentheses are optional in an assignment like this:

```py
developer = 'Alice', 34, 'Rust Developer'
print(developer) # ('Alice', 34, 'Rust Developer')
```

To create a tuple with one element, you need a trailing comma:

```py
single_value = (5,)
print(single_value) # (5,)

not_a_tuple = (5)
print(not_a_tuple) # 5
```

An empty tuple is written as `()`.

Tuples are similar to lists, but while lists are a mutable data type, tuples are immutable. This means that once a tuple is created, its element references cannot be replaced, added, or removed.

If you try to update one of the items in the tuple, you will get a `TypeError`:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')
programming_languages[0] = 'JavaScript'

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: 'tuple' object does not support item assignment
"""
```

## Mutable Objects inside Tuples

A tuple can contain a mutable object, such as a list. The tuple's immutability does not prevent changes to that contained object:

```py
def add_greeting(values):
    values[0].append('hi')

greetings = (['hello'],)
original_list = greetings[0]

add_greeting(greetings)
print(greetings) # (['hello', 'hi'],)
print(greetings[0] is original_list) # True
```

The function mutates the list inside the tuple. The tuple still holds a reference to the same list. Assigning a different list to `greetings[0]` would raise a `TypeError`, because that would replace the tuple's element reference.

## Accessing Tuple Elements

To access an element from a tuple, you can use bracket notation and the index number:

```py
developer = ('Alice', 34, 'Rust Developer')
developer[1] # 34
```

If you need to access elements starting from the end of a tuple, then you can use negative indexing. Here is an example of using a negative index to access the second to last element in a tuple:

```py
numbers = (1, 2, 3, 4, 5)
numbers[-2] # 4
```

If you try to pass in an index number that exceeds or equals the length of the tuple, then you will receive an `IndexError` like this:

```py
numbers = (1, 2, 3, 4, 5)
numbers[7]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
IndexError: tuple index out of range
"""
```

## Using the `tuple()` Constructor

Another way to create a tuple is by using the `tuple()` constructor like this:

```py
developer = 'Jessica'
tuple(developer) # ('J', 'e', 's', 's', 'i', 'c', 'a')
```

For the `tuple()` constructor, you can pass in different iterables like strings, lists, and even other tuples. 

## Checking If an Element Is in a Tuple

To check if an item is in a tuple, you can use the `in` keyword like this:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')

'Rust' in programming_languages # True
'JavaScript' in programming_languages # False
```

## Unpacking Values from a Tuple

You can also unpack items from a tuple just like you did with lists:

```py
developer = ('Alice', 34, 'Rust Developer')
name, age, job = developer

print(name) # 'Alice'
print(age) # 34
print(job) # 'Rust Developer'
```

In this example, `name` has the value `'Alice'`, `age` has the value `34`, and `job` has the value `'Rust Developer'`.

If you need to collect any remaining elements from a tuple, you can use the asterisk (`*`) operator like this:

```py
developer = ('Alice', 34, 'Rust Developer')
name, *rest = developer

print(name) # 'Alice'
print(rest) # [34, 'Rust Developer']
```

Here, `name` has the value `'Alice'`, and `rest` is a list comprised of the number `34` and the string `'Rust Developer'`.

## Using Tuples in Simultaneous Assignment

You can create a tuple on the right side of an assignment and unpack it into the variables on the left:

```py
first, second = 10, 20
print(first) # 10
print(second) # 20
```

Python evaluates all the expressions on the right side before assigning their values to the variables on the left. This lets you swap two values without a temporary variable:

```py
first, second = 10, 20
first, second = second, first

print(first) # 20
print(second) # 10
```

## Returning a Tuple from a Function

A function can return a tuple by placing comma-separated values after `return`:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

coordinates = get_coordinates()
print(coordinates) # (10, 20)
```

The comma-separated values create one tuple, which the function returns. Here, `return first, second` is equivalent to `return (first, second)`. The parentheses are optional.

You can unpack the returned tuple directly into variables:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

x, y = get_coordinates()
print(x) # 10
print(y) # 20
```

## Slicing Tuples

Just like with a list, you can use the slice operator on a tuple to extract a portion of it. Here is an example of extracting the items `'pie'` and `'cookies'` into a separate tuple:

```py
desserts = ('cake', 'pie', 'cookies', 'ice cream')
desserts[1:3] # ('pie', 'cookies')
```

Remember that the first number represents the starting index for the extraction while the second number represents the ending index. But note that the item at the ending index is not included in the extracted tuple.

## Comparing Tuples

Python compares tuples lexicographically. This means it compares corresponding elements from left to right. The first unequal pair determines the result:

```py
print((1, 9) < (2, 0)) # True
```

Here, `1` is less than `2`, so the first tuple is smaller. Python does not need to compare `9` and `0`.

If the first elements are equal, Python moves to the next pair:

```py
print((1, 3) < (1, 5)) # True
```

Both tuples start with `1`, so Python compares `3` with `5` to determine the result.

If all corresponding elements are equal, the shorter tuple is smaller. Tuples with the same length and equal corresponding elements are equal:

```py
print((1, 2) < (1, 2, 3)) # True
print((1, 2) == (1, 2)) # True
```

The values in the first unequal pair must support the ordering comparison. Otherwise, Python raises a `TypeError`:

```py
print((1, 3) < (1, 'five'))
# TypeError: '<' not supported between instances of 'int' and 'str'
```

Here, the first elements are equal, but Python cannot order the integer `3` and the string `'five'`.

Later elements do not need to be comparable if an earlier pair already determines the result:

```py
print((1, 3) < (2, 'five')) # True
```

## Removing Elements from a Tuple

If you need to remove an item from a tuple, that isn't possible because tuples are immutable. So this example will produce an error:

```py
developer = ('Jane Doe', 23, 'Python Developer')
del developer[1]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: "tuple" object doesn't support item deletion
"""
```

## Choosing between Tuples and Lists

So when might you use a tuple over a list?

If you need a dynamic collection of elements where you can add, remove, and update elements, then you should use a list. If you need a sequence whose element references stay fixed, you can use a tuple. Remember that any mutable objects it contains can still change.
