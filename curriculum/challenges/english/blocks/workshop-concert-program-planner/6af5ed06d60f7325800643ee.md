# --description--

To add an item at a specific position, you can use the `insert()` method. It takes the index where the new item should go, followed by the item itself. The items from that index onward shift one position to the right:

```py
fruits = ['apple', 'banana', 'cherry']
fruits.insert(1, 'blueberry')
print(fruits) # ['apple', 'blueberry', 'banana', 'cherry']
```

The conductor wants the two Slavonic dances to be played one after the other. Use `insert()` to add the string `Slavonic Dance No. 1` to `pieces`, right before `Slavonic Dance No. 8`.
