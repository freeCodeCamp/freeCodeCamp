# --description--

In this workshop, you'll practice working with lists by planning the program of an orchestra concert.

As you learned in the previous lessons, a list is an ordered collection of items. You create a list by placing comma-separated items inside square brackets:

```py
fruits = ['apple', 'banana', 'cherry']
```

Create a variable named `pieces` and assign it a list containing the strings `Carnival Overture`, `Song to the Moon`, and `Silent Woods`, in this order.
