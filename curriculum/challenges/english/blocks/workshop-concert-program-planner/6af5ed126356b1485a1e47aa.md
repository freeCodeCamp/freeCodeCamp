# --description--

Assigning a list to another variable doesn't create a copy of the list. Both variables refer to the same list, so the second variable is called an alias. Any change made through one of them is visible through the other.

Create a variable named `printed_program` and assign it `pieces`. Then, use `append()` to add the string `Humoresque No. 7` as an encore to the end of `pieces`, and print `printed_program`.

In the terminal, you'll see that the encore appears in `printed_program` too, even though you added it to `pieces`.

With that, your concert program planner is complete.
