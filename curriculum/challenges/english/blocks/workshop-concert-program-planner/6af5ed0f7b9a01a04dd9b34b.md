# --description--

Unpacking lets you assign the items of a list to multiple variables in a single line. You can use a starred variable to collect any remaining items into a list:

```py
fruits = ['apple', 'banana', 'cherry']
first, *rest = fruits
print(first) # apple
print(rest) # ['banana', 'cherry']
```

Unpack `pieces` into three variables: `opening` for the first item, `middle` for all the items in between, and `closing` for the last item. Then, print `opening`, `middle`, and `closing` in three separate `print()` calls.
