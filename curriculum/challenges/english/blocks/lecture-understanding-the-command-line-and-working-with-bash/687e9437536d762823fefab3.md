# --description--

Let's learn about command line shortcuts you can use to speed up productivity.

Terminal and command line shortcuts can help you streamline your workflows and maximize your productivity. For Linux and macOS, which can both trace their roots to Unix, many of these shortcuts will be the same. But for Windows, there will be some differences.

## The <kbd>Up Arrow</kbd> and <kbd>Down Arrow</kbd> Shortcuts

The first shortcut is the <kbd>Up Arrow</kbd> key. Pressing this key will allow you to cycle backwards through your command history, one command at a time. The <kbd>Down Arrow</kbd> key, then, can be used to cycle forwards through your command history. These two keys allow you to quickly cycle through the commands you have previously run to find one you need to run again.

## Autocompletion with the <kbd>Tab</kbd> Key

Many shells will also offer an auto-complete feature, proposing commands based on what you have started to type. The <kbd>Tab</kbd> key can be used to fill in the rest of the suggestion, quickly populating your command line with the full syntax. What gets suggested depends on the shell, the command you are typing, and how your shell is configured. For example, when you are typing a command name, Bash and zsh suggest matching commands, and when you are typing an argument, they usually suggest matching file and directory names. PowerShell can complete commands, parameter names, variables, and file paths.

## The <kbd>Control</kbd> + <kbd>L</kbd> Shortcut

Sometimes a command may result in a lot of output on your terminal. This extra noise can get in the way, or become disruptive to your workflow. In *nix based terminals found on Linux and macOS devices, you can press <kbd>Control</kbd> + <kbd>L</kbd> to clear the entire screen and start with a fresh clean prompt. In PowerShell, <kbd>Control</kbd> + <kbd>L</kbd> also clears the screen by default, and you can run the `cls` command for the same result.

## The <kbd>Control</kbd> + <kbd>C</kbd> Shortcut

If you need to interrupt a command to stop its execution, you can press <kbd>Control</kbd> + <kbd>C</kbd>. This sends an interrupt request to the command running in the foreground, which usually stops it and returns you to a new prompt, allowing you to continue with whatever else you may need to work on. Some programs handle this request themselves, so they might ask you to confirm or keep running instead. For PowerShell users, <kbd>Control</kbd> + <kbd>C</kbd> is also used to copy text - and will only work to interrupt a command when the context is not ambiguous (such as when there is no text selected to copy).

## *nix-Based Terminal Shortcuts

The next couple of shortcuts are only available in *nix based terminals, and do not have a PowerShell alternative.

There may be times when you need to multitask, pausing a command while you work on another. Pressing <kbd>Control</kbd> + <kbd>Z</kbd> suspends the command running in the foreground and returns you to the command line, where you can continue your work. A suspended command is paused, not running. If you want it to keep running in the background, use the `bg` command. When you need to bring it back to the foreground, use the `fg` command.

And finally, there may be commands you need to run twice in a row. You can press the <kbd>Up Arrow</kbd> key to cycle backwards to the previously run command, but you can also type two exclamation points (`!!`) into the command line and hit <kbd>Enter</kbd> - this will automatically run the last executed command.
