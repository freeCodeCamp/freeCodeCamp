# --description--

You have learned that assignment creates an alias and that a dictionary's `.copy()` method creates a shallow copy. A shallow copy has a separate outer dictionary, but nested objects are still shared. Now that you know how to import modules, you can use the standard library's `copy` module to copy nested collections too.

## Creating a Deep Copy

The `copy.deepcopy()` function recursively copies nested collections. For a dictionary containing a list, it creates a new outer dictionary and a separate nested list:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
deep_copy = copy.deepcopy(original)

print(deep_copy == original) # True
print(deep_copy is original) # False
print(deep_copy['items'] is original['items']) # False

deep_copy['items'].append('fruit')
print(original['items']) # ['bread', 'cheese']
print(deep_copy['items']) # ['bread', 'cheese', 'fruit']
```

The dictionaries initially have equal contents, but neither the outer dictionary nor the nested list is shared between them. Appending to the copied list leaves the original list unchanged.

## Comparing Assignment, Shallow Copying, and Deep Copying

Let's create all three forms from the same dictionary:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
alias = original
shallow_copy = original.copy()
deep_copy = copy.deepcopy(original)

print(alias is original) # True
print(shallow_copy is original) # False
print(deep_copy is original) # False

print(alias['items'] is original['items']) # True
print(shallow_copy['items'] is original['items']) # True
print(deep_copy['items'] is original['items']) # False
```

Continuing with these objects, change a top-level entry through each name:

```python
alias['name'] = 'Picnic'
shallow_copy['name'] = 'Snack'
deep_copy['name'] = 'Dinner'

print(original['name']) # Picnic
print(alias['name']) # Picnic
print(shallow_copy['name']) # Snack
print(deep_copy['name']) # Dinner
```

The alias refers to the original dictionary, so assigning through `alias` changes that dictionary. Each copy has its own outer dictionary, so replacing its `name` entry affects only that copy.

Next, mutate the nested lists:

```python
alias['items'].append('water')
shallow_copy['items'].append('fruit')
deep_copy['items'].append('soup')

print(original['items']) # ['bread', 'cheese', 'water', 'fruit']
print(alias['items']) # ['bread', 'cheese', 'water', 'fruit']
print(shallow_copy['items']) # ['bread', 'cheese', 'water', 'fruit']
print(deep_copy['items']) # ['bread', 'cheese', 'soup']
```

The original dictionary, its alias, and the shallow copy all refer to the same list. Changes through any of those references are visible through the others. The deep copy has its own list, so its changes remain separate.

This also works with dictionaries nested inside lists:

```python
import copy

original = {'meals': [{'name': 'Lunch', 'items': ['bread']}]}
deep_copy = copy.deepcopy(original)
deep_copy['meals'][0]['items'].append('fruit')

print(original['meals'][0]['items']) # ['bread']
print(deep_copy['meals'][0]['items']) # ['bread', 'fruit']
```

Here, `deepcopy()` copies the outer dictionary, the `meals` list, the dictionary inside that list, and its `items` list. The example uses built-in dictionaries and lists; deep copying does not mean that every possible Python object is duplicated.

Use assignment when you want another name for the same object. Use a shallow copy when a separate outer collection is enough and sharing nested objects is acceptable. Use a deep copy when changes to these nested collections should leave the original collections unchanged.
