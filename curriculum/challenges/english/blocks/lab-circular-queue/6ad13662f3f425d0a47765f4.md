# --description--

In this lab, you will implement a circular queue data structure. A circular queue is a fixed-size queue where the last position is connected back to the first, forming a circle. It follows the FIFO (first-in, first-out) principle and efficiently reuses space by wrapping around when the end of the queue is reached.

**Objective:** Fulfill the user stories below and get all the tests to pass to complete the lab.

**User Stories:**

1. You should define a class named `CircularQueue`. It should accept one parameter representing the maximum number of elements the queue can hold.

1. The `CircularQueue` class should have the following methods:

   - `enqueue`: takes an element and adds it to the back of the queue. If the queue is full, it should return `False` without adding the element. Otherwise it should return `True`.
   - `dequeue`: removes the element at the front of the queue and returns it. If the queue is empty, it should return `None`.
   - `front`: returns the element at the front of the queue without removing it. If the queue is empty, it should return `None`.
   - `is_empty`: returns `True` if the queue has no elements, and `False` otherwise.
   - `is_full`: returns `True` if the queue has reached its maximum capacity, and `False` otherwise.
   - `size`: returns the current number of elements in the queue.

```py
class CircularQueue:
    def __init__(self, capacity):
        self.capacity = capacity
        self.queue = [None] * capacity
        self.head = 0
        self.tail = 0
        self.current_size = 0

    def enqueue(self, element):
        if self.is_full():
            return False
        self.queue[self.tail] = element
        self.tail = (self.tail + 1) % self.capacity
        self.current_size += 1
        return True

    def dequeue(self):
        if self.is_empty():
            return None
        element = self.queue[self.head]
        self.queue[self.head] = None
        self.head = (self.head + 1) % self.capacity
        self.current_size -= 1
        return element

    def front(self):
        if self.is_empty():
            return None
        return self.queue[self.head]

    def is_empty(self):
        return self.current_size == 0

    def is_full(self):
        return self.current_size == self.capacity

    def size(self):
        return self.current_size
```
