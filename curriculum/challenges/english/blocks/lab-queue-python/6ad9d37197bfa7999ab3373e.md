# --description--

In this lab, you will build a queue class. A queue follows the FIFO (first-in, first-out) principle: elements are added to the back of the queue and removed from the front.

**Objective:** Fulfill the user stories below and get all the tests to pass to complete the lab.

**User Stories:**

1. You should define a class named `Queue`. A new instance of `Queue` should start empty.

1. The `Queue` class should have the following methods:

   - `enqueue`: takes an element and adds it to the back of the queue.
   - `dequeue`: removes the element at the front of the queue and returns it. If the queue is empty, it should return `None`.
   - `front`: returns the element at the front of the queue without removing it. If the queue is empty, it should return `None`.
   - `size`: returns the number of elements in the queue.
   - `is_empty`: returns `True` if the queue has no elements, and `False` otherwise.

```py
class Queue:
    def __init__(self):
        self.collection = []

    def enqueue(self, item):
        self.collection.append(item)

    def dequeue(self):
        if self.is_empty():
            return None
        return self.collection.pop(0)

    def front(self):
        if self.is_empty():
            return None
        return self.collection[0]

    def size(self):
        return len(self.collection)

    def is_empty(self):
        return len(self.collection) == 0
```
