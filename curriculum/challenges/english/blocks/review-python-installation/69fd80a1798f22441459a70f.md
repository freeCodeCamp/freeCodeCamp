## Installing Python in Your Local Environment

- **Installation**: The easiest way to install Python on Windows and macOS is to download the installer from the official Python website (`https://www.python.org/`). On Linux, most major distributions like Ubuntu, Debian, and Fedora already include Python, so you check the installed version first and only install a distribution-specific package if Python 3 is missing.
- **Setting up on macOS**: Download and open the `.pkg` installer and follow the prompts. When it finishes, double-click the `Install Certificates.command` file and let the terminal process complete to finish the setup.
- **Setting up on Windows**: Download and run the `.msix` Python Install Manager. Afterward, the `python`, `py`, and `pymanager` commands are available, running `python` with no runtime installed will install one automatically, and you can accept the optional prompt to add an aliases directory (for commands like `python3.14.exe`) to your `PATH`.
- **Setting up on Linux**: Open a terminal and run `python --version` or `python3 --version`. If neither reports a Python 3 version, look for an installation package at `https://www.python.org/` or search online for the recommended way to install Python for your distribution.

## Verifying the Installation

- **Checking the version**: Confirm the installation by running `python --version` or `python3 --version` in a terminal.
- **`python` vs. `python3`**: On some older macOS and Linux systems, `python` can refer to Python 2. If `python --version` reports a Python 2 version, use `python3` for your code from then on. Python 2 is end-of-life and should not be used for new development.

## Terminal

- **Definition**: A terminal is a text-based interface that lets you interact with your computer by typing commands. Each operating system comes with a default terminal app. On macOS, you can use the Terminal app. On Windows, you can use Command Prompt or PowerShell. On Linux, each desktop environment has its own default terminal app, like GNOME Terminal or Konsole.

## Code Editors and IDEs

- **IDE**: IDE stands for Integrated Development Environment, and it has features including a code editor, testing tools, a terminal, and more.
- **Popular Code Editors and IDEs for Python**: VS Code, PyCharm, and Spyder.

## Running Python Scripts

- **Setting up your editor**: Open your project folder in VS Code and create a `.py` file. Install Microsoft's Python extension from the Extensions view or by running `code --install-extension ms-python.python` (on macOS, the `code` command must be added to your `PATH` first). The extension adds Python support to the editor but does not install Python itself.
- **Choosing an interpreter**: Run `Python: Select Interpreter` from the Command Palette to point the editor at a Python 3 interpreter you installed earlier.
- **Running your code**: Click the run button (the play icon in the upper-right corner of VS Code) to run the current file in a terminal. You can also run a script manually from the folder that contains it:

```bash
cd python-projects
python main.py
```

Use `python3 main.py` instead if `python3` is the command that reports Python 3 on your system.

## Using the Python Interactive Shell

- **Starting the shell**: Open a terminal and run `python` or `python3` (use whichever reported a Python 3 version). The `>>>` prompt means Python is waiting for a command. Try printing `"Hello, world!"`:

```python
print("Hello, world!")
```

- **Read, Evaluate, Print, Loop cycle (REPL)**: The interpreter reads your input, evaluates it, prints the result, and loops back to the `>>>` prompt so you can type another command.
- **Invalid input**: Entering something that is not valid Python, such as `something random`, produces a `SyntaxError: invalid syntax` message, and the shell returns to the prompt.
- **Exiting the shell**: Type `exit()`, press <kbd>Ctrl</kbd> + <kbd>D</kbd> on macOS or Linux, or press <kbd>Ctrl</kbd> + <kbd>Z</kbd> followed by <kbd>Enter</kbd> on Windows.
- **When to use it**: The interactive shell is best for small experiments and quick exploration. For longer programs or work across multiple files, use a code editor or IDE.
