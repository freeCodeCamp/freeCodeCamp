## Python in Your Local Environment

- **Downloading and Installing Python**: On Windows and macOS, download the installer from the official Python website (`https://www.python.org/`). Most major Linux distributions (like Ubuntu, Debian, and Fedora) come with Python pre-installed; if Python 3 is missing, install it using your distribution's package manager.
- **Platform Setup**:
  - On macOS, run the `.pkg` installer and double-click `Install Certificates.command` in the newly created Applications folder to finish setup.
  - On Windows, install the Python Install Manager (`.msix` package), which provides the `python`, `py`, and `pymanager` commands (and automatically installs a runtime if none is present). An optional prompt allows adding aliases like `python3.14.exe` to your `PATH`.
- **Verifying Version**: Run `python --version` or `python3 --version` in your terminal to confirm your installation. Use whichever command reports a Python 3 version. On some older systems, `python` may be absent or point to Python 2, which is end-of-life and should not be used.
- **Terminal**: A text-based interface that lets you interact with your computer by typing commands. Each operating system comes with a default terminal app: Terminal on macOS, Command Prompt or PowerShell on Windows, and tools like GNOME Terminal or Konsole on Linux.
- **IDE**: IDE stands for Integrated Development Environment and combines features such as a code editor, testing tools, and a terminal.
- **Popular Code Editors and IDEs for Python**: VS Code, PyCharm, and Spyder.
- **Setting Up Your Editor (VS Code)**:
  - Open or create a project folder, then create a script file with a `.py` extension (such as `main.py`).
  - Install Microsoft's Python extension via the Extensions view or from the terminal using `code --install-extension ms-python.python` (on macOS, this requires installing the `code` command in `PATH` first).
  - The extension acts as a bridge but does not install the language files. Open the Command Palette (<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> on Windows/Linux or <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> on macOS) and run `Python: Select Interpreter` to choose your installed Python 3 runtime.
- **Running Code Locally**: In VS Code, you can click the play button in the upper right corner to run your script in a terminal. Alternatively, navigate to your project folder using `cd` and run the script manually:

```bash
cd python-projects
python main.py
```

If your system uses `python3` for Python 3, run:

```bash
python3 main.py
```

## Using the Python Interactive Shell

- **Definition**: An interactive shell is a program that lets you type commands one at a time and see the results immediately. Start it by typing `python` or `python3` (whichever points to Python 3) into your terminal and pressing <kbd>Enter</kbd>. The `>>>` prompt indicates Python is waiting for input.

```md
>>> print("Hello, world!")
Hello, world!
>>> 
```

- **Read, Evaluate, Print, Loop cycle (REPL)**: The interpreter reads input, evaluates it, prints the output, and loops back to show `>>>`. If you enter an invalid command (such as `something random`), the REPL outputs an error such as `SyntaxError: invalid syntax` and displays the prompt again.
- **Exiting the Shell**: You can exit by typing `exit()` and pressing <kbd>Enter</kbd>, or by pressing <kbd>Ctrl</kbd> + <kbd>D</kbd> on macOS/Linux, or <kbd>Ctrl</kbd> + <kbd>Z</kbd> followed by <kbd>Enter</kbd> on Windows.
- **When to Use the Shell**: The interactive shell is ideal for quick experiments, testing individual functions, and small code explorations. For longer programs or multi-file projects, use a code editor or IDE.
