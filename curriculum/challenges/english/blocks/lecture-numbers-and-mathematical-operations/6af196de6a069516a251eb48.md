# --description--

Sometimes a number is fine for your calculations but looks a bit unfinished when you print it. If you're showing a price, for example, `12.50` may feel more natural than `12.5`.

An f-string lets you tidy up how the number looks without modifying the original value available so it can be available for other calculations.

## What :.2f Means

The expression, `f"{value:.2f}"` displays `value` with exactly two digits after the decimal point.

Inside the braces, each character has a role it plays:

- The colon, `:` introduces the format specification
- `.2` selects two decimal places
- `f` selects fixed-point presentation, which displays the number in decimal notation.

That means `print(f"{12.5:.2f}")` produces `12.50`, while still leaving the initial value unchanged:

```py
value = 12.5

print(f"{value:.2f}") #12.50
print(value) #12.5
```

This happens because Python adds a trailing zero to the `value` to fill out the two decimal places.

On the other hand, a value like `12.3456` with the `.2f` expression produces `12.35` because it must be rounded for display:

```py
value = 12.3456

print(f"{value:.2f}") #12.35
print(value) #12.3456
```

## Formatting with F-String Produces a String

An f-string produces a string:

```py
value = 12.3456
display = f"{value:.2f}"

print(display) #12.35
print(value) #12.3456

print(type(display)) #<class 'str'>
print(type(value)) #<class 'float'>
```

This means you can save the resulting string separately and still use the original number in calculations.

## How `round()` Differs from F-String Formatting

An expression like `round(value, 2)` gives you a numeric result you can use in further calculations.

Printing that result uses Python's usual number display, so trailing zeros are not guaranteed:

```py
value = 12.5

rounded_value = round(value, 2)
formatted_value = f"{value:.2f}"

print(rounded_value) # 12.5
print(formatted_value) # 12.50
```

## Why Formatting Doesn't Make Floating Point Calculations Exact

Some decimal numbers like `0.1` and `0.2` can only be approximated as floats. Therefore, their sum can look a little surprising when printed directly:

```py
total = 0.1 + 0.2

print(total) # 0.30000000000000004
print(f"{total:.2f}") # 0.30
```

As you can see, the f-string rounds the sum for display. Any calculation that uses `total` still uses the same floating-point value.
