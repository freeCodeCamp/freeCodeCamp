# --description--

In this lab, you will implement additional operations for a linked list data structure, building on the `LinkedList` class you created in the previous workshop.

**Objective:** Fulfill the user stories below and get all the tests to pass to complete the lab.

**User Stories:**

1. Your `LinkedList` class should have a `contains` method that takes an element as its argument. It should return `True` if the element exists in the linked list, and `False` otherwise.
1. Your `LinkedList` class should have a `get_at` method that takes an index as its argument. It should return the element at the given index in the linked list. If the index is out of bounds, it should return `None`.
1. Your `LinkedList` class should have an `insert_at` method that takes an index and an element as its arguments. It should insert the element at the given position in the linked list and update the `length` attribute. An index equal to the length of the list is valid and should add the element at the end. If the index is out of bounds, it should not modify the list.
1. Your `LinkedList` class should have a `remove_at` method that takes an index as its argument. It should remove the node at the given index in the linked list and update the `length` attribute. If the index is out of bounds, it should not modify the list.
1. Your `LinkedList` class should have a `clear` method that removes all elements from the linked list, resetting it to an empty state.

**Note:** Some later tests rely on earlier methods. For example, if `get_at` is not implemented correctly, tests for methods like `insert_at` and `remove_at` may fail even when those methods are close to correct.

```py
class LinkedList:
    class Node:
        def __init__(self, element):
            self.element = element
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element)
        if self.is_empty():
            self.head = node
        else:
            current_node = self.head
            while current_node.next is not None:
                current_node = current_node.next
            current_node.next = node
        self.length += 1

    def remove(self, element):
        previous_node = None
        current_node = self.head
        while current_node is not None and current_node.element != element:
            previous_node = current_node
            current_node = current_node.next
        if current_node is None:
            return
        elif previous_node is not None:
            previous_node.next = current_node.next
        else:
            self.head = current_node.next
        self.length -= 1

    def contains(self, element):
        current_node = self.head
        while current_node is not None:
            if current_node.element == element:
                return True
            current_node = current_node.next
        return False

    def get_at(self, index):
        if index < 0 or index >= self.length:
            return None
        current_node = self.head
        for _ in range(index):
            current_node = current_node.next
        return current_node.element

    def insert_at(self, index, element):
        if index < 0 or index > self.length:
            return
        node = self.Node(element)
        if index == 0:
            node.next = self.head
            self.head = node
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            node.next = previous_node.next
            previous_node.next = node
        self.length += 1

    def remove_at(self, index):
        if index < 0 or index >= self.length:
            return
        if index == 0:
            self.head = self.head.next
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            previous_node.next = previous_node.next.next
        self.length -= 1

    def clear(self):
        self.head = None
        self.length = 0
```
