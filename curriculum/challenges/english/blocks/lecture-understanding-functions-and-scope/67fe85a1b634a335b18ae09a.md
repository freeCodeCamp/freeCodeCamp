# --description--

Scope determines where you can use a variable in your code.

Python has additional scope rules. For now, focus on local and global scope.

A variable created outside a function has global scope. You can use it both inside and outside functions.

A variable created inside a function has local scope. You can only use it inside that function. Function parameters are local variables too.

Here is an example of local and global scope:

```python
tax_rate = 0.1

def calculate_tax(price):
    tax = price * tax_rate
    return tax

print(calculate_tax(50)) # 5.0
print(tax_rate) # 0.1
print(tax) # NameError: name 'tax' is not defined
```

The `tax_rate` variable is global because it is created outside the function. The `calculate_tax` function can read it, and the second `print()` call can read it too.

The `price` parameter and the `tax` variable are local to `calculate_tax`. They are available while that function runs, but not outside it. The last `print()` call raises a `NameError` because `tax` is not defined in the global scope.
