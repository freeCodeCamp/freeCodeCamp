# --description--

Before working with the readings, you need to remove the error codes.

As you learned in the previous lessons, the `filter()` function keeps only the items of an iterable for which a function returns a truthy value. Instead of defining that function with `def`, you can pass a lambda function directly to `filter()`:

```py
numbers = [1, 2, 3, 4]
even_numbers = filter(
    lambda num: num % 2 == 0,
    numbers
)
```

Create a variable named `valid_readings`. Assign it the result of passing `filter()` a lambda function and `readings`. The lambda function should take a parameter named `reading` and check if `reading` is not equal to `-999`.

Then, print `valid_readings` instead of `readings`.
