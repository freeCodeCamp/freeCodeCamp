# --description--

In this workshop, you'll practice list comprehensions and lambda functions by cleaning the readings of a temperature sensor and comparing them to the usual average temperature of its location.

The sensor reports temperatures in tenths of a degree Celsius, so a reading of `215` means `21.5` °C. When it fails to read the temperature, it writes the error code `-999` instead.

Create a variable named `readings` and assign it the list `[215, 243, -999, 280, 316, 339, -999, 262, 305]`.

Then, create a variable named `average_temperature` and assign it the float `28.0`. This is the usual average temperature for the location, already in degrees Celsius, and you'll compare the readings to it.
