# --description--

In the terminal, you'll see some values like `-3.6999999999999993` instead of `-3.7`. This happens because floats can't represent every decimal number exactly, so small errors can appear after arithmetic operations.

The `round()` function rounds a number to the number of decimal places you pass as the second argument:

```py
print(round(3.14159, 2)) # 3.14
```

Wrap `temperature - average` in a `round()` call to round each difference to one decimal place.
