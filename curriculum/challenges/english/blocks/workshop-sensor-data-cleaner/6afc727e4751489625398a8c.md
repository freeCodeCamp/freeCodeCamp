# --description--

Now you'll turn the differences into text labels like `+3.6 °C`. Positive numbers are printed without a sign, so you'll need to add a `+` in front of them.

To include only the items that meet a condition, you can add a trailing `if` at the end of a list comprehension:

```py
numbers = [1, 2, 3, 4]
even_numbers = [num for num in numbers if num % 2 == 0]
print(even_numbers) # [2, 4]
```

Create a variable named `difference_labels`. Use a list comprehension to assign it a list containing `f'+{difference} °C'` for each `difference` in `differences`, but only if `difference` is greater than `0`.

Then, print `difference_labels` instead of `differences`.

In the terminal, you'll see only 3 labels for 7 temperatures. A trailing `if` leaves out the items that don't match the condition, so there's no way to tell which temperature each label belongs to. You'll fix this in the next step.
