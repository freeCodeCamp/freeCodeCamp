# --description--

Now you need to pair each temperature with its label.

The `map()` function can take more than one iterable. On every call, it passes one item from each iterable to the function, so the function needs one parameter per iterable:

```py
first = [1, 2, 3]
second = [10, 20, 30]
totals = list(map(
    lambda a, b: a + b,
    first,
    second
))
print(totals) # [11, 22, 33]
```

Create a variable named `report`. Assign it the result of passing `map()` a lambda function, `temperatures`, and `difference_labels`, wrapped in a `list()` call. The lambda function should take two parameters, `temperature` and `difference_label`, and return `f'{temperature} °C ({difference_label})'`.

Then, print `report` instead of `difference_labels`.
