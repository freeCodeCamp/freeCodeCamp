# --description--

In the terminal, you should see something like `<filter object at 0x...>` instead of the readings. This happens because `filter()` returns an iterator, which gives you the items one at a time instead of storing them all in a list.

To collect the items of an iterator into a list, you can pass it to the `list()` function:

```py
numbers = [1, 2, 3, 4]
even_numbers = list(filter(
    lambda num: num % 2 == 0,
    numbers
))
print(even_numbers) # [2, 4]
```

Wrap the `filter()` call assigned to `valid_readings` in a `list()` call. In the terminal, you should see the readings without the `-999` error codes.
