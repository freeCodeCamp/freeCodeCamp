# --description--

The `map()` function calls a function on each item of an iterable, and returns an iterator of the results. Like with `filter()`, you can pass it a lambda function:

```py
prices = [10, 20, 30]
discounted = list(map(
    lambda price: price * 0.9,
    prices
))
print(discounted) # [9.0, 18.0, 27.0]
```

Now you need to convert the valid readings from tenths of a degree to degrees.

Create a variable named `temperatures`. Assign it the result of passing `map()` a lambda function and `valid_readings`, wrapped in a `list()` call. The lambda function should take a parameter named `reading` and return `reading` divided by `10`.

Then, print `temperatures` instead of `valid_readings`.
