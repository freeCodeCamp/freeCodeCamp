# --description--

To get a label for every difference, you need a conditional expression before `for` instead of a trailing `if`:

```py
numbers = [1, 2, 3, 4]
labels = [
    'Even' if num % 2 == 0 else 'Odd'
    for num in numbers
]
print(labels) # ['Odd', 'Even', 'Odd', 'Even']
```

Remove the trailing `if` from your list comprehension. Then, change the expression before `for` to a conditional expression that evaluates to `f'+{difference} °C'` if `difference` is greater than `0`, and to `f'{difference} °C'` otherwise. Negative numbers already have a `-` sign, so they only need the unit.
