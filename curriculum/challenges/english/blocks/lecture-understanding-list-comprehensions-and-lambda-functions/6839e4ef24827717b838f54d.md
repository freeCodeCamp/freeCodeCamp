# --description--

Throughout the previous lessons, you have been defining functions by using the `def` keyword like this:

```py
def square(num):
    return num ** 2

print(square(4)) # 16
```

In the previous lesson, you passed functions like `is_long_word` and `to_fahrenheit` to `map()` and `filter()`. A function that accepts another function as an argument is called a higher-order function. Defining a separate function with `def` every time you need to pass a short function to a higher-order function can be a bit verbose. Instead, you can write a lambda function, which is a function without a name, directly where you need it.

The syntax of a lambda function looks like this:

```py
lambda parameters: expression
```

After the `lambda` keyword, you list the parameters of the function. The colon separates the parameters from a single expression, and the result of that expression is automatically returned, without the need for a `return` statement.

Here's what the `square()` function looks like when refactored into a lambda function:

```py
lambda num: num ** 2
```

Here, `num` is the parameter, and `num ** 2` is the expression whose result is returned. As mentioned earlier, lambda functions are anonymous, so this function no longer has the name `square` associated with it.

A lambda function can also have more than one parameter. Just like with functions defined with `def`, you separate the parameters with commas:

```py
lambda a, b: a + b
```

This lambda function takes two parameters, `a` and `b`, and returns their sum.

Lambda functions are great when you need to pass them to higher-order functions like this:

```py
numbers = [1, 2, 3, 4, 5]

even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # [2, 4]
```

In this example, we have a list of numbers and want to create a new list of even numbers. So we pass in a lambda function as one of the arguments to the `filter()` function. The `filter()` function calls the lambda function on each number, and keeps only the numbers for which `x % 2 == 0` is `True`. Then `list()` collects them into a new list containing the numbers `2` and `4`.

When working with lambda functions it is important to be aware of best practices. For example, it is not a good practice to assign a lambda function to a variable like this:

```py
numbers = [1, 2, 3, 4, 5]

square = lambda x: x ** 2
squared_numbers = list(map(square, numbers))
print(squared_numbers) # [1, 4, 9, 16, 25]
```

This defeats the purpose of using anonymous functions. In this case, you should use a regular function, like this:

```py
numbers = [1, 2, 3, 4, 5]

def square(num):
    return num ** 2

squared_numbers = list(map(square, numbers))
print(squared_numbers) # [1, 4, 9, 16, 25]
```

Also, you should avoid creating lambda functions that are difficult to read or unnecessarily complicated, like this:

```py
result = (lambda x: (x**2 + 2*x - 1) if x > 0 else (x**3 - x + 4))(3)
print(result)  # 14
```

While this function runs fine and produces the correct result of `14`, it is not easy to read or look at. In this case, it would be better to create a separate function with an `if/else` statement, and then call that function:

```py
def calculate_expression(x):
    if x > 0:
        return x**2 + 2*x - 1
    else:
        return x**3 - x + 4

print(calculate_expression(3))  # 14
```

Both regular functions and lambda functions have their use cases in Python programs. If you are dealing with a single inline expression, then you might consider using a lambda function. Otherwise, using a regular function would be the way to go.
