# --description--

At the end of the `__str__` method, return the email summary in this format:

```md
[status] From: sender | Subject: subject
```

Where `status` is the status of the email, `sender` is the sender's name and `subject` is the subject of the email.

When several summaries are printed one under another, they are easier to read if the parts line up like table columns. Since `Read` is shorter than `Unread`, and sender names have different lengths, use format specifiers to give each one a fixed width:

- Left-align `status` in a width of `6`.
- Left-align the sender's name in a width of `10`.

For example, a read email from `Alice` with the subject `Hello` would look this way:

```md
[Read  ] From: Alice      | Subject: Hello
```
