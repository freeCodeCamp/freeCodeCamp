# --description--

Time to display the sender and receiver information. To make the names line up neatly below each other, give the text in front of each name a fixed width with a format specifier.

Add two print statements to the `display_full_email` method:

- `'From:'` left-aligned in a width of `10`, followed by the sender's name.
- `'To:'` left-aligned in a width of `10`, followed by the receiver's name.

For example, with `Alice` as the sender and `Bob` as the receiver, the two lines would look like this:

```md
From:     Alice
To:       Bob
```
