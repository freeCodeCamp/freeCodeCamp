# --description--

Now, show the timestamp when displaying the full email.

Below the subject, print `'Received:'` left-aligned in a width of `10`, followed by the timestamp formatted with `strftime` as `'%Y-%m-%d %H:%M'`. Use the following format:

```md
Received: date
```

Where `date` is formatted as `'%Y-%m-%d %H:%M'`. `Received:` is the longest of them, which is why they all use a width of `10`: it leaves exactly one space after it.

class Inbox:
    def __init__(self):

    def receive_email(self, email):
        self.emails.append(email)

    def list_emails(self):
        if not self.emails:
            print('Your inbox is empty.\n')
            return
        print('\nYour Emails:')
        for i, email in enumerate(self.emails, start=1):
            print(f'{i:>2}. {email}')

    def read_email(self, index):
        if not self.emails:
            print('Inbox is empty.\n')
            return
        actual_index = index - 1
        if actual_index < 0 or actual_index >= len(self.emails):
            print('Invalid email number.\n')
            return
        self.emails[actual_index].display_full_email()

    def delete_email(self, index):
        if not self.emails:
            print('Inbox is empty.\n')
            return
        actual_index = index - 1
        if actual_index < 0 or actual_index >= len(self.emails):
            print('Invalid email number.\n')
            return
