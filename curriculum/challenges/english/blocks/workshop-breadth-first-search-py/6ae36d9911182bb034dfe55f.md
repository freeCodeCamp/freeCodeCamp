# --description--

As you learned, BFS uses a queue to keep track of the nodes to visit. The first node added to the queue is the first one to be removed, and this is what makes the search proceed level by level.

You'll use a list as the queue, adding nodes at the end and removing them from the start.

After setting the distance of `root`, create a variable named `queue` and assign it a list containing `root`.
