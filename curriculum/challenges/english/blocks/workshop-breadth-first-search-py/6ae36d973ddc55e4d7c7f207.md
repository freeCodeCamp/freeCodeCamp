# --description--

Before the search starts, no node has been reached yet, so the distance of every node is unknown.

A common way to represent this is with infinity, which you can create in Python with `float('inf')`. Any node that still has a distance of infinity when the search is done can't be reached from `root`.

The nodes of the graph are labeled from `0` to `len(graph) - 1`. Between `distances = {}` and the `return` statement, create a `for` loop that iterates over `range(len(graph))` using `node` as the loop variable. Inside the loop, set the distance of `node` to `float('inf')`.
