# --description--

Soon you'll add each neighbor to the queue so it gets visited too. But the graph is undirected, so when node `1` is visited, node `0` will show up as its neighbor. Adding nodes that were already reached would overwrite their distances and keep adding them to the queue forever.

A node that has already been reached no longer has a distance of infinity, so you can use that to skip it.

Update the condition of your `if` statement so that it also checks if the distance of `neighbor` is equal to `float('inf')`.
