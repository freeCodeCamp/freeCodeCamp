# --description--

BFS explores a graph level by level, so it reaches every node through the fewest possible edges. This means you can use it to find the distance, measured in number of edges, between a starting node and every other node.

Above `graph`, create a function named `bfs` with two parameters: `graph`, the adjacency matrix, and `root`, the node where the search starts.

Inside the function, create a variable named `distances` and assign it an empty dictionary. It will map each node to its distance from `root`. Then, return `distances`.
