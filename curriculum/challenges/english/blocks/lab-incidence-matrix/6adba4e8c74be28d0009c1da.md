# --description--

In this lab, you will build a function that represents an undirected graph as an incidence matrix. An undirected graph has nodes connected by edges, where each edge can be traversed in either direction.

An incidence matrix is a list of lists with one row for each node and one column for each edge. A value of `1` indicates that the node is an endpoint of that edge, and a value of `0` indicates that it is not. Unlike an adjacency matrix, which relates nodes to other nodes, an incidence matrix relates nodes to edges.

For example, a graph with three nodes and the edges `[(0, 1), (1, 2)]` has this incidence matrix:

```py
[
    [1, 0],
    [1, 1],
    [0, 1]
]
```

The first column represents the edge between nodes `0` and `1`, and the second column represents the edge between nodes `1` and `2`.

**Objective:** Fulfill the user stories below and get all the tests to pass to complete the lab.

**User Stories:**

1. You should define a function named `incidence_matrix` that takes two arguments:
   - A non-negative integer representing the number of nodes. The nodes are numbered starting from `0`.
   - A list of tuples representing the edges. Each tuple contains two distinct node numbers. All node numbers will be valid, and no edge will be repeated.
2. Your function should return the incidence matrix as a list of lists of integers. The rows should follow node-number order, and the columns should follow the order of the edges in the input list.
3. Each column should contain `1` in the two rows corresponding to the endpoints of its edge and `0` in every other row. The order of the endpoints in a tuple should not affect the result.
4. Nodes with no connected edges should have rows containing only zeros. If there are no edges, your function should return an empty list for each node. If there are no nodes, it should return an empty list.

# --solutions--

```py
def incidence_matrix(num_nodes, edges):
    matrix = [[0] * len(edges) for _ in range(num_nodes)]

    for column, (first, second) in enumerate(edges):
        matrix[first][column] = 1
        matrix[second][column] = 1

    return matrix
```
