# --description--

In a previous lesson on numbers and mathematical operations, you used a format specification like `.2f` in an f-string to control how many decimal places a number shows.

Format specifications can also control how much space a value takes up and where it sits. This is useful when you want output to line up in neat columns.

## Setting a Minimum Width and Alignment

A number after the colon sets the minimum width of the field, which is the number of characters the value should take up. If the value is shorter than that, Python adds spaces until it reaches that width. Here's an example:

```py
print(f'|{"Tea":8}|') # |Tea     |
print(f'|{"Coffee":8}|') # |Coffee  |

print(len(f'{"Tea":8}')) # 8
print(len(f'{"Coffee":8}')) # 8
```

Using specific symbols before the width controls where the value sits inside the field. Here are those specific symbols:

- Lesser than (`<`) aligns the value to the left
- Greater than (`>`) aligns the value to the right
- Caret (`^`) centers the value.

Here are those three symbols in action:

```py
label = 'Tea'

print(f'|{label:<8}|') # |Tea     |
print(f'|{label:>8}|') # |     Tea|
print(f'|{label:^8}|') # |  Tea   |
```

`'Tea'` contains three characters, so Python adds five spaces to reach a width of `8`. 

- With `<`, the spaces go after the value
- With `>`, the spaces go before it
- With `^`, the spaces are split between both sides to center the text.

If it happens the space can't be split evenly, the extra space goes on the right:

```py
label = 'Tea'

print(f'|{label:^9}|') # |   Tea   |
print(f'|{label:^8}|') # |  Tea   |
```

If you leave out the alignment symbol, strings are left-aligned by default, while numbers are right-aligned:

```py
label = 'Tea'
amount = 4.5

print(f'|{label:8}|')     # |Tea     |
print(f'|{amount:7.2f}|') # |   4.50|
```

## Using a Fill Character

By default, Python pads with spaces. To use a different character for the padding, insert the character right before the alignment symbol:

```py
label = 'Tea'

print(f'{label:*^9}') # ***Tea***
print(f'{label:-<8}') # Tea-----
```

In `*^9`, the `*` is the fill character, `^` centers the value, and `9` is the minimum width. Note that you can only use a fill character together with an alignment symbol.

## Combining Width and Precision

You can combine alignment and width with the precision you learned about in the previous lesson, all in one format specification:

```py
amount = 4.5

print(f'|{amount:>7.2f}|') # |   4.50|
```

The example above means, align right, use a minimum width of `7`, and show two decimal places. Python formats the number as `4.50` first, which is four characters long, and then adds three spaces in front to fill the width of `7`.

## Building a Statement Row

You can put a label and an amount together on one line. If you use the same format specification for every row, the columns line up:

```py
print(f'{"Tea":.<12}{4.5:>8.2f}')
print(f'{"Sandwich":.<12}{12.75:>8.2f}')
print(f'{"Cookie":.<12}{2:>8.2f}')

# Output:
# Tea.........    4.50
# Sandwich....   12.75
# Cookie......    2.00
```

Each label is left-aligned in a field of `12` characters and padded with dots, while each amount is right-aligned in a field of `8` characters, so the decimal points line up.

## Width Is a Minimum, Not a Maximum

The width only adds padding. It never cuts a value short. If the value is longer than the specified width, all the value is displayed:

```py
label = 'Long description'

print(f'|{label:<8}|') # |Long description|
```

If you want to limit the length, you need to shorten the string yourself. One way to do that is to slice it before the formatting:

```py
label = 'Long description'

print(f'|{label[:8]:<8}|') # |Long des|
```

The same applies to numbers. In the example below, the formatted amount needs eight characters, so it ignores the specified width of `7`:

```py
amount = 12345.67

print(f'|{amount:7.2f}|') # |12345.67|
```

In `:7.2f`, the `7` is a minimum width, not a limit on how long the amount can be. Python never cuts off digits to make a number fit.

This is why you should pick widths large enough for the values you expect, or the columns won't line up.
