# --description--

**Variables** allow you to store values, such as strings, so you can use them later.

To create one, write the variable name, followed by the assignment operator (`=`) and the value you want to store, like this:

```py
person_face = '(^_^)'
```

Create a variable named `person_face` and assign it the string you just created.
