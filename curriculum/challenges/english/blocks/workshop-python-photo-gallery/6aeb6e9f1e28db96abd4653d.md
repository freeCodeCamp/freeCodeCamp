# --description--

The quotes surrounding a string denote the start and end of the string and are not included in the string's value. You can see that they are not displayed in the terminal.

The first picture for your photo gallery will show two people. Create a new string below your existing code that looks like this:

```py
'(^_^)'
```

This string will be the face for each person.

# --hints--
