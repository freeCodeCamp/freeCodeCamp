# --description--

Next, you will add a cat photo to your gallery. You want a string for the top half of your cat like this:

```py
'('.')__/'
```

But if you tried to assign the above string to a variable, Python would treat the second apostrophe as the end of the string and the rest of the text would cause an error.

To include a quote inside a string, add a backslash (`\`) in front of it. This is called **escaping**. The backslash and quote together form an **escape sequence**.

Create a `cat_top` variable and assign it the string:

```py
'(\'.\')__/'
```
