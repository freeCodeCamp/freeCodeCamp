# --description--

Next, you will add a cat photo to your gallery. You want the top half of your cat to look like this:

```py
'('.')___/'
```

If you try to assign that string to a variable, Python would see the apostrophe inside it as the end of the string and give you an error.

To include a quote inside a string, add a backslash (`\`) in front of it. This is called **escaping**. The backslash and quote together form an **escape sequence**.

Create a `cat_top` variable and assign it the string:

```py
'(\'.\')__/'
```
