# --description--

Before saving a contact, you need to check if it's already in the contact book.

Accessing a key that doesn't exist with square brackets raises a `KeyError`. Instead, the `.get()` method returns the value of a key if it exists, and `None` if it doesn't:

```py
person = {'name': 'Ada'}
print(person.get('name'))  # Ada
print(person.get('age'))  # None
```

Inside your function, create a variable named `contact` and assign it the result of calling `.get()` on `contacts` with `name` as the argument. Then, print `contact` insteaf of `details`.

Since `James` isn't in `contacts` yet, you should see `None` in the terminal.
