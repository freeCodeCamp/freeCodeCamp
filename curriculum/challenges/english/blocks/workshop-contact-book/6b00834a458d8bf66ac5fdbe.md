# --description--

To count something with a dictionary, you can use `.get()` with a default value of `0`. The first time a key appears, `.get()` returns `0`, and every next time it returns the current count:

```py
counts[key] = counts.get(key, 0) + 1
```

Replace `print(group)` with a line that sets the value of the `group` key of `counts` to the result of calling `.get()` on `counts` with `group` and `0` as arguments, plus `1`.

Contacts without a group are counted under the `None` key, so you can also see how many contacts do not belong to a specific group.

With that, your contact book is complete.
