# --description--

The `.update()` method adds the key-value pairs of the dictionary you pass to it, replacing the values of any keys that are already there:

```py
person = {'name': 'Ada', 'age': None}
person.update({'age': 36})
print(person)  # {'name': 'Ada', 'age': 36}
```

Before printing `contact`, call `.update()` on `contact` and pass it `details`. You should see James's details printed in the terminal.
