# --description--

The `.get()` method accepts an optional second argument, which is the value to return when the key doesn't exist, instead of `None`:

```py
person = {'name': 'Ada'}
print(person.get('age', 0))  # 0
```

A new contact should start as an empty dictionary, so that you can add its details to it.

Pass an empty dictionary as the second argument to `.get()`. You should see `{}` printed in the terminal.
