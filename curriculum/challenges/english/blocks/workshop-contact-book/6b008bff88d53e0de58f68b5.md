# --description--

A dictionary stores data as key-value pairs, where each key is unique and is used to access its value. Strings are commonly used as keys:

```py
my_dict = {'name': 'Ada', 'age': 23}
```

You are going to represent each contact with a dictionary whose keys are strings naming the contact's details, such as `phone`, and whose values are strings containing those details.

Add a key-value pair to the `contact` dictionary, with the string `phone` as the key and the string `555-0101` as the value.
