# --description--

To display each field on its own line, you need to iterate over both the keys and the values of the contact.

The `.items()` method returns the key-value pairs of a dictionary. When you iterate over it with two loop variables, the first one gets the key and the second one gets the value:

```py
person = {'name': 'Ada', 'age': 36}
for key, value in person.items():
    print(key, value)
# name Ada
# age 36
```

Replace `print(contact)` with a `for` loop that iterates over `contact.items()`, using `field` and `value` as the loop variables. Inside the loop, print `field` and `value`.
