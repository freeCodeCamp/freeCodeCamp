# --description--

A dictionary value can be any object, including another dictionary. This lets you store several pieces of information under a single key:

```py
books = {
    'Dune': {'author': 'Frank Herbert', 'year': 1965}
}
```

Create a variable named `contacts` and assign it a dictionary with the string `Maria` as its only key, and the dictionary you assigned to `contact` as its value. Then, delete the `contact` variable and your `print()` call.
