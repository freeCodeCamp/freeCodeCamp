# --description--

The elevator should keep serving requests as long as there are any left. A `while` loop is perfect for this, because it repeats as long as its condition is true. Here's a reminder of the syntax:

```py
while condition:
    # code to repeat
    ...
```

A non-empty list is truthy and an empty list is falsy, so you can use a list as the condition of the loop to make it run until the list is empty.

Create a `while` loop that runs as long as `requests` is not empty. Inside the loop, use `pop(0)` to remove the first request from `requests` and assign it to a variable named `target`. Then, print `target`.

Since `pop(0)` makes the list shorter on every iteration, the list eventually becomes empty and the loop stops. Without that, the condition would never become false, and the loop would run forever.
