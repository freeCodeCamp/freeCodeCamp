# --description--

What if someone requests the floor the elevator is already on?

Change the requests in your function call to `[3, 3, 7, 2]`. In the terminal, you'll see `Arrived at floor 3` printed twice, even though the elevator didn't move the second time.

def run_elevator(requests, start_floor):
    current_floor = start_floor
    floors_traveled = 0

    while requests:
        target = requests.pop(0)

        while current_floor != target:
            if current_floor < target:
                current_floor += 1
            else:
                current_floor -= 1
            floors_traveled += 1

        print(f'Arrived at floor {current_floor}')
