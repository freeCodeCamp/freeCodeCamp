# --description--

Like a `for` loop, a `while` loop can have an `else` clause. The code in the `else` clause runs when the loop ends normally, but not when the loop is stopped by `break`.

Add an `else` clause to the outer `while` loop. Inside it, print the string `All requests served`.

There's a stop request in the list, so the `else` clause won't run for now.

def run_elevator(requests, start_floor):
    current_floor = start_floor
    floors_traveled = 0

    while requests:
        target = requests.pop(0)

        if target == 'stop':
            print('Emergency stop!')
            break

        if target == current_floor:
            print(f'Already on floor {target}')
            continue

        while current_floor != target:
            if current_floor < target:
                current_floor += 1
            else:
                current_floor -= 1
            floors_traveled += 1

        print(f'Arrived at floor {current_floor}')
