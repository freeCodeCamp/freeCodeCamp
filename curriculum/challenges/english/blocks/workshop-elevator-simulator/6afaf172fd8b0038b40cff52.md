# --description--

In this workshop, you'll practice working with `while` loops by building a function that simulates an elevator moving between floors.

Define a function named `run_elevator` with two parameters: `requests`, a list of the floors the elevator is asked to go to, and `start_floor`, the floor where the elevator starts.

Inside the function, create a variable named `current_floor` and assign it `start_floor`.
