# --description--

In software development, a library is like a toolbox for developers.

Instead of having to implement every single part of the code yourself from scratch, a library gives you pre-written and reusable code, like functions, classes, and data structures that you can use in your projects.

The Python standard library is a collection of modules and packages included with Python. Third-party packages are developed separately and usually need to be installed before you can use them. The standard library provides solutions for common programming tasks, such as:

* Interacting with the operating system.

* Working with files.

* Networking.

* Working with date and time.

* Performing mathematical operations.

* Using regular expressions.

* Testing and debugging your code.

* And much more!

Some examples of standard-library modules are `math`, `random`, `re` (short for "regular expressions"), and `datetime`.

The `math` module has helpful functions for performing more complex mathematical operations.

The `random` module is helpful for generating random numbers.

The `re` module is used for working with regular expressions.

The `datetime` module is helpful for working with dates and times in Python.

Modules can provide classes as well as functions and constants. Here is an example of a class from the `datetime` module. We create a date object that represents July 15, 1959. Then, we assign that `date` object to a variable and access the day, month, and year individually using dot notation:

```python
import datetime
birthday = datetime.date(1959, 7, 15)
print(birthday.day)    # 15
print(birthday.month)  # 7
print(birthday.year)   # 1959
```

To find a module for a particular task, browse the [Python Standard Library reference](https://docs.python.org/3/library/index.html), where modules are grouped by topic. Each module's documentation explains what it provides and how to use it. For example, the [`datetime` documentation](https://docs.python.org/3/library/datetime.html) describes the classes and methods available for working with dates and times.

You can also use the `help()` function to display the documentation of a module or function. Note that `help()` is not currently available in the freeCodeCamp editor.

For example, this code displays information about the `math` module:

```py
import math
help(math)
```

Here is an excerpt of the output:

You can also get the documentation of a specific function:

```py
import math
help(math.comb)
```

This is the output:

```md
Help on built-in function comb in module math:

comb(n, k, /)
    Number of ways to choose k items from n items without repetition and without order.
    
    Evaluates to n! / (k! * (n - k)!) when k <= n and evaluates
    to zero when k > n.
    
    Also called the binomial coefficient because it is equivalent
    to the coefficient of k-th term in polynomial expansion of the
    expression (1 + x)**n.
    
    Raises TypeError if either of the arguments are not integers.
    Raises ValueError if either of the arguments are negative.
```

To discover what names a module provides, you can use the `dir()` function. It lists functions, like `math.floor` to round down a number, and constants, like `math.e` (Euler's number) and `math.pi`. It also lists some other names you will learn about later in the curriculum:

```py
import math
print(dir(math))
```
