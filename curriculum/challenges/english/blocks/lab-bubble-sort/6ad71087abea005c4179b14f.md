# --description--

Bubble sort works by repeatedly stepping through a list, comparing adjacent elements, and swapping them if they are out of order. After each pass, the largest unsorted value "bubbles up" to the end of the list. The algorithm stops when a full pass completes without any swaps.

Bubble sort has quadratic time complexity in the average and worst cases, so it's rarely used in practice.

**Objective:** Fulfill the user stories below and get all the tests to pass to complete the lab.

**User Stories:**

1. You should define a function named `bubble_sort` with one parameter that represents the list of items.
1. Your `bubble_sort` function should sort the list in place from smallest to largest and return it.
1. Your `bubble_sort` function should follow the bubble sort algorithm, comparing adjacent elements and swapping them only when the left element is greater than the right one.
1. Your `bubble_sort` function should stop as soon as a pass through the list completes without any swaps.
1. Your `bubble_sort` function should not use either the built-in `sort()` method or `sorted()` function.

```js
({
  test: () =>
    runPython(`
from collections import UserList

class CustomList(UserList):
    def __init__(self, *args, **kwargs):
        self._record = []
        super().__init__(*args, **kwargs)

    def __setitem__(self, key, value):
        self._record.append((key, value))
        super().__setitem__(key, value)

def expected_swaps(items):
    items = list(items)
    swaps = []
    swapped = True
    while swapped:
        swapped = False
        for j in range(len(items) - 1):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swaps.append({(j, items[j]), (j + 1, items[j + 1])})
                swapped = True
    return swaps

for values in ([33, 1, 89, 2, 67, 245], [4, 4, 2, 2, 1, 4, 3]):
    list_to_sort = CustomList(values)
    bubble_sort(list_to_sort)
    record = list_to_sort._record
    expected = expected_swaps(values)
    assert len(record) == 2 * len(expected)
    actual = [set(record[i:i + 2]) for i in range(0, len(record), 2)]
    assert actual == expected
    `)
});

def bubble_sort(items):
    n = len(items)
    for i in range(n):
        swapped = False
        for j in range(n - 1 - i):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swapped = True
        if not swapped:
            break
    return items
```
