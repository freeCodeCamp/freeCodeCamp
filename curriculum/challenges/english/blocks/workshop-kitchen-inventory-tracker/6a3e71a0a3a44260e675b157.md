# --description--

A function can call another function and use its returned value. For example:

```py
def calculate_sum(a, b):
    return a + b

def show_total(a, b):
    total = calculate_sum(a, b)
    print(total)

show_total(3, 4) # 7
```

Here, `show_total` calls `calculate_sum`, assigns its returned value to the local variable `total`, and prints it.
