# --description--

Now you can finally answer the question from earlier: why did the global number of eggs stay at `1`? When a function returns a value, it doesn't automatically overwrite your existing variables. You must explicitly save that new value!

Remember that function parameters are local variables. When you pass the global `available_eggs` to `make_fried_egg`, its local parameter initially refers to the same integer. The assignment `available_eggs = use_eggs(available_eggs, 1)` reassigns only that local parameter to the returned count. It does not reassign the global variable, which still refers to `1`.

To update your actual kitchen inventory, overwrite the global `available_eggs` variable with the new number of eggs returned by your `make_fried_egg` function.

At the very bottom of your code, call the `make_fried_egg` function, passing `available_eggs` as the argument, and assign the result back to the global `available_eggs` variable.

available_eggs = 1
available_flour = 2
available_sugar = 3

def check_kitchen_stock():
    total_items = available_eggs + available_flour + available_sugar
    print(f'The kitchen has {total_items} total items:')
    print(f'- {available_eggs} eggs')
    print(f'- {available_flour} flour')
    print(f'- {available_sugar} sugar')

check_kitchen_stock()

def use_eggs(available_eggs, eggs_to_use):
    if eggs_to_use > available_eggs:
        print('The kitchen does not have enough eggs.')
        return available_eggs

    print(f'{eggs_to_use} egg(s) used out of {available_eggs} available.')
    return available_eggs - eggs_to_use

use_eggs(available_eggs, 1)
print(available_eggs)

def make_fried_egg(available_eggs):
    has_enough_eggs = available_eggs >= 1

    if has_enough_eggs:
        available_eggs = use_eggs(available_eggs, 1)
        print('Made a fried egg. Yummy!')
    else:
        print('Could not make a fried egg. Not enough eggs!')

    return available_eggs
