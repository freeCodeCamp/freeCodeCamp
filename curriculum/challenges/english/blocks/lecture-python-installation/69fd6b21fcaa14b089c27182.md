## Installing a Code Editor or IDE

In the previous lesson, you learned how to install Python on your local device. In this lesson, you will learn how to run Python code locally.

Before you can start building your Python scripts locally, you will need to install a code editor or IDE. IDE stands for integrated development environment. An IDE combines features such as a code editor, testing tools, and a terminal.

One popular code editor that many developers use is VS Code. Visit `https://code.visualstudio.com/download` to download VS Code, which supports macOS, Windows, and Linux. This is the editor that will be used in this lesson.

Other common choices for Python development include the following:

- PyCharm
- Spyder

## Creating a Python File

After installing VS Code, open it and select `File`, then `Open Folder`. Choose or create a folder for your project. From there, you can choose or create a folder for your project. For extra practice outside of the lesson, you might want a folder named `python-projects`.

Open Explorer in VS Code's left sidebar. Select the `New File` icon, which looks like a piece of paper with a plus sign. Create a file named `main.py` and press <kbd>Enter</kbd>. The `.py` extension identifies it as a Python file.

Open up your `main.py` file and type the following code:

```py
print("Hello, world!")
```

## Install the Python extension

To install Microsoft's official Python extension, follow the specific steps below:

  Method A: Inside the Application

  1. Open the Extensions view by clicking the icon of four building blocks on the left-side Activity Bar, or press the shortcut:
    * Windows / Linux: <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd>
    * macOS: <kdb>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>X</kdb>
  2. Type `Python` into the search bar at the top.
  3. Look for the top result named Python, ensuring the publisher listed underneath is Microsoft.
  4. Click the blue <kbd>Install</kbd> button.

  Method B: Terminal / Command line

  If you prefer configuring your workspace from a command line, you can download it directly from the Visual Studio Marketplace by executing:

```bash
code --install-extension ms-python.python
```

  Important next step: Select an Interpreter

  The extension acts as a bridge, but it does not contain the actual Python language files. You must install a Python interpreter separately from the Official Python Website if you haven't already.

  Once Python is installed on your operating system, tie it to your editor:

  1. In VS Code, open any folder or a file ending in .py.
  2. Open the Command Palette using
    * Windows / Linux <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>
    * macOS: <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>
  3. Type and select `Python: Select Interpreter`.
  4. Choose the installed version of Python 3 from your machine's list. It will now show up natively in your workspace status bar.

## Running Your Python Script

To run this code, you have a few options. The first option is to click on the run button which looks like a play button located in the upper right hand corner. That will open a terminal and run your Python script there. You should see the text `Hello, world!`.

Another option is to open a terminal and manually run the program using:

```bash
python main.py
```

You must run this command from the folder where `main.py` is saved. For example, if `main.py` is inside a folder called `python-projects`, first use the following in the terminal:

```bash
cd python-projects
```

Then run:

```bash
python main.py
```

## Using `python3` Instead of `python`

In some environments, especially on macOS and Linux systems where Python 2 and Python 3 are both installed, you may need to use `python3` instead of `python`. This is common when the `python` command either does not exist or points to an older version of Python.

```bash
python3 main.py
```
