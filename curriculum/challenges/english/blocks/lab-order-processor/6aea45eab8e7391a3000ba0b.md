# --description--

In this lab, you will process e-commerce orders and handle the errors that come up along the way.

**Objective:** Fulfill the user stories below and get all the tests to pass to complete the lab.

The data you will work with has the same structure as the variables in the starting code:

- An **order** is a dictionary with:
  - `order_id`: an integer that identifies the order.
  - `products`: a list of dictionaries, each with a `product_id` and the `quantity` requested.
  - `discount_code`: a string, or `None` if the order has no discount code.
  - `status`: a string describing the state of the order.
- An **order history** is a list of orders.
- An **inventory** is a dictionary whose keys are product IDs and whose values are dictionaries with the `product` name, the `quantity` in stock, and the `price` of a single unit.
- The **discount codes** are a dictionary whose keys are the codes and whose values are the discount rates, for example `0.1` for a 10% discount.

**User Stories:**

1. You should have a function named `find_order` with two parameters: an order ID and an order history, in this order.
1. `find_order` should:
   - return the order from the given order history whose `order_id` is equal to the given order ID.
   - raise a `ValueError` with the message `Order ID {order_id} not found in order history.` if no order matches the given order ID.
1. You should have a function named `verify_availability` with two parameters: an order and an inventory, in this order.
1. `verify_availability` should:
   - raise a `ValueError` with the message `Product ID {product_id} is not in the inventory.` if a product in the order is missing from the given inventory.
   - raise a `ValueError` with the message `Insufficient stock for product ID {product_id}: requested {quantity}, available {available}.` if the quantity requested for a product is greater than its quantity in the given inventory.
   - not raise anything if every product in the order is available in the requested quantity.
1. You should have a function named `get_discount_rate` with two parameters: an order and the discount codes, in this order.
1. `get_discount_rate` should:
   - return `0.0` if the order's `discount_code` is `None`.
   - raise a `ValueError` with the message `Invalid discount code: {discount_code}.` if the order's `discount_code` is not one of the given discount codes.
   - return the rate of the order's `discount_code` otherwise.
1. You should have a function named `process_order` with one parameter: the ID of the order to process.
1. `process_order` should work on the global `order_history`, `inventory`, and `discount_codes` variables. It should use `find_order`, `verify_availability`, and `get_discount_rate` to process the order, and handle the `ValueError` they raise so that it never reaches the caller.
1. When no order in the `order_history` matches the given order ID, `process_order` should:
   - print `Error processing order {order_id}: {error message}`, where `{error message}` is the message of the `ValueError` raised by `find_order`, and print nothing else.
   - leave the `inventory` and the `discount_codes` unchanged.
1. When the order exists but cannot be fulfilled, because a product is missing from the `inventory`, because the requested quantity is not available, or because the discount code is invalid, `process_order` should:
   - print `Error processing order {order_id}: {error message}`, where `{error message}` is the message of the `ValueError` raised by `verify_availability` or `get_discount_rate`.
   - set the order's `status` to `failed`.
   - leave the `inventory` and the `discount_codes` unchanged.
   - print `Order {order_id} processing completed. Current status: failed`.
1. When the order can be fulfilled, `process_order` should:
   - print `Order {order_id} total: ${total}`, with the discount applied and the total rounded to two decimal places.
   - set the order's `status` to `processed`.
   - subtract the ordered quantities from the `inventory`.
   - remove the discount code the order used from the `discount_codes`, so that each code can only be used once.
   - print `Order {order_id} processing completed. Current status: processed`.

**Note:** You've been provided with an inventory, order history, and discount codes you can use to test your code.

def find_order(order_id, order_history):
    for order in order_history:
        if order['order_id'] == order_id:
            return order
    raise ValueError(f'Order ID {order_id} not found in order history.')

def set_order_status(order, status):
    order['status'] = status

def get_discount_rate(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is None:
        return 0.0
    if discount_code not in discount_codes:
        raise ValueError(f'Invalid discount code: {discount_code}.')
    return discount_codes[discount_code]

def consume_discount_code(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is not None:
        del discount_codes[discount_code]

def verify_availability(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        quantity = product['quantity']
        if product_id not in inventory:
            raise ValueError(f'Product ID {product_id} is not in the inventory.')
        available = inventory[product_id]['quantity']
        if available < quantity:
            raise ValueError(
                f'Insufficient stock for product ID {product_id}: '
                f'requested {quantity}, available {available}.'
            )

def calculate_total(order, inventory):
    products = order['products']
    total = 0.0
    for product in products:
        product_id = product['product_id']
        price = inventory[product_id]['price']
        quantity = product['quantity']
        total += price * quantity
    return total

def reserve_stock(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        inventory[product_id]['quantity'] -= product['quantity']

def process_order(order_id):
    try:
        order = find_order(order_id, order_history)
    except ValueError as e:
        print(f'Error processing order {order_id}: {e}')
        return

    try:
        verify_availability(order, inventory)
        discount_rate = get_discount_rate(order, discount_codes)
        total = calculate_total(order, inventory)
    except ValueError as e:
        set_order_status(order, 'failed')
        print(f'Error processing order {order_id}: {e}')
    else:
        reserve_stock(order, inventory)
        consume_discount_code(order, discount_codes)
        set_order_status(order, 'processed')
        print(f'Order {order_id} total: ${total * (1 - discount_rate):.2f}')

    print(f'Order {order_id} processing completed. Current status: {order["status"]}')
