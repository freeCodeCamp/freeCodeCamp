# --description--

Insertion sort builds a sorted portion at the beginning of the list, one element at a time. It starts by treating the first element as sorted. Then it takes the next element and moves it backwards into the sorted portion, shifting or swapping each larger element one position to the right, until it reaches an element that is less than or equal to it. This repeats for every remaining element until the whole list is sorted.

Insertion sort has quadratic time complexity in the average and worst cases, but it runs in linear time when the list is already sorted.

**Objective:** Fulfill the user stories below and get all the tests to pass to complete the lab.

**User Stories:**

1. You should define a function named `insertion_sort` with one parameter that represents the list of items.
1. Your `insertion_sort` function should sort the list in place from smallest to largest and return it.
1. Your `insertion_sort` function should follow the insertion sort algorithm, inserting each element, from left to right, into its correct position within the sorted portion at the beginning of the list.
1. Your `insertion_sort` function should stop moving an element backwards as soon as it reaches an element that is less than or equal to it.
1. Your `insertion_sort` function should not use either the built-in `sort()` method or `sorted()` function.

        sorted(items[:i]) + items[i:]

    insertion_sort(list_to_sort)
    states = iter(list_to_sort._states)
    state = next(states)

            state = next(states)

```py
def insertion_sort(items):
    for i in range(1, len(items)):
        current = items[i]
        j = i - 1
        while j >= 0 and items[j] > current:
            items[j + 1] = items[j]
            j -= 1
        items[j + 1] = current
    return items
```
