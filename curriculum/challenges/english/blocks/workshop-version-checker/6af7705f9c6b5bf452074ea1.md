# --description--

To find the latest release, you need the versions in order. Tuples are compared element by element, from left to right, so sorting a collection of version tuples puts them in the correct version order.

Define a function named `check_for_update` with two parameters, `installed` and `releases`. Inside it, create a variable named `sorted_releases` and assign it the result of calling `sorted()` with `releases` as its argument.

Then, print `sorted_releases`.
