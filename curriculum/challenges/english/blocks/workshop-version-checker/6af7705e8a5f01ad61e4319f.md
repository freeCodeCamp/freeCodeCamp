# --description--

In this workshop, you'll practice working with tuples by building a program that checks if an app needs an update.

A version such as `2.1.0` can be stored as a tuple of three integers: the major, minor, and patch numbers.

Create a variable named `releases` and assign it a tuple containing the following version tuples, in this order:

```py
(1, 9, 0), (2, 0, 0), (1, 9, 1), (2, 1, 0),
(2, 1, 1), (2, 2, 0), (1, 9, 2), (2, 2, 1)
```

The releases are listed in the order they were published, not from the lowest to the highest version. The old `1.9` line kept getting fixes even after version `2.0.0` was out.
