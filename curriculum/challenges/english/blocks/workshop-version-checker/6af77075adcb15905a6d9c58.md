# --description--

As a last test, try to release a version that already exists. Version `2.3.0` was released when you published a minor release earlier, so a minor release built from `2.2.0` would be a duplicate.

Call `release_version` with `releases`, the string `minor`, and `(2, 2, 0)` as the arguments, and assign the result to `releases`.

With that, your version checker is complete.
