# --description--

If the installed version is not the latest, your function should say what kind of update is available. When the major numbers are different, it's a major update.

You can access the major number of a version with index `0`. Add an `if` statement that checks if the major number of `installed` is less than the major number of `latest`. If it is, create a variable named `update_type` and assign it the string `major update`.
