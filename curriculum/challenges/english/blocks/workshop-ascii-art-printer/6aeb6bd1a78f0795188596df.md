# --description--

In this workshop, you will be using variables to print ASCII art to the terminal.

Variables have a name and a value separated by an equal sign (`=`). Here is an example that assigns the value `hello world` to a variable named `my_variable`:

```py
my_variable = 'hello world'
```

In the editor, create a variable named `person_head`, and give it the value `(^_^)`. Be sure to add quotes around the value.
