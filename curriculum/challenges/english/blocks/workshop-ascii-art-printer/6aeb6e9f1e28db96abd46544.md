# --description--

Now your person and cat look good.

Comments in Python code start with `#`. Here's an example:

```py
# This is a comment
```

Everything after the `#` is part of the comment and will not get executed when you run your code. Add a comment at the top of your file that reads `Python program to print my cat and I as ASCII art`.

With that, the workshop is complete.
