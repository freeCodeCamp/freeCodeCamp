# --description--

In this lab, you will plan which shifts to work to earn as much as possible, using dynamic programming. You are given a list with the wage for each day's shift. You can work any shift you like, but you need to rest after each shift, so you can't work two days in a row. Your goal is to find the highest total pay you can earn, and which days to work to earn it.

For example, with the wages `[60, 150, 40, 30, 200, 70]`, working every other day earns either `60 + 40 + 200`, which is `300`, or `150 + 30 + 70`, which is `250`. But the best plan is to work days `1` and `4`, and rest on both days `2` and `3`, which earns `150 + 200`, which is `350`. Sometimes, resting for more than one day in a row pays more.

**Objective:** Fulfill the user stories below and get all the tests to pass to complete the lab.

**User Stories:**

1. You should have a function named `max_earnings` with one parameter: `wages`, a list of positive integers where each element is the wage for that day's shift.
1. `max_earnings` should use a dynamic programming approach to find the highest total pay that can be earned without working two days in a row.
1. `max_earnings` should return a tuple with two elements:
   - the highest total pay.
   - a list of the indices of the days to work to earn that pay, in ascending order. If more than one set of days earns the highest pay, any of them can be returned.
1. If `wages` is empty, `max_earnings` should return `(0, [])`.
1. `max_earnings` should not modify `wages`.

**Note:** For each day, there are only two choices: skip it, and keep the best total up to the day before, or work it, and add its wage to the best total up to two days before. Store the best total for each day so you don't have to work it out again.

```py
def max_earnings(wages):
    best = [0] * (len(wages) + 1)

    for day, wage in enumerate(wages, 1):
        skip_day = best[day - 1]
        work_day = wage + (best[day - 2] if day >= 2 else 0)
        best[day] = max(skip_day, work_day)

    days = []
    day = len(wages)
    while day > 0:
        if best[day] == best[day - 1]:
            day -= 1
        else:
            days.append(day - 1)
            day -= 2

    return best[-1], days[::-1]
```
