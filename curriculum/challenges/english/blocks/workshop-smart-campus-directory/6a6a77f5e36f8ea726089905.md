# --description--


You are building a Smart Campus Directory. The campus data comes to you as a single, deeply nested JavaScript 
object called `rawData`, which has already been provided for you in the seed code.

Take a moment to look at its shape: each key is a department name, and its value holds a `Dept_code` along with
a `programs` array. Each program then holds its own array of `instructors`.

Log `rawData` to the console so you can inspect this nested structure before working with it.
