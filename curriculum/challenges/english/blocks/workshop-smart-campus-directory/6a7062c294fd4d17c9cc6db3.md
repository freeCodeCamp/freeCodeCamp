# --description--


Inside `normalizeDirectory`, there are four empty objects: `departmentsById`, `programsById`, `instructorsById`, and `instructorsByEmail`.

These are called `lookup tables` — objects that use an ID (or another unique value, like an email) as the key, so you can jump straight to a piece of data instead of looping through an array to find it. This is much faster than searching, since accessing an object property by key is a direct lookup, not a scanning through complete object.
