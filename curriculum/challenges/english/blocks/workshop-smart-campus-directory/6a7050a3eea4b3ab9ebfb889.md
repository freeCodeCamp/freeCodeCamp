# --description--

In this step, you will map out the structure you're working with. 
In `rawData`, there are multiple layer of data are nested together,
like this: `department -> programs -> instructors`.

Now imagine you needed to find an instructor by their email address. With `rawData` in its 
current shape, you'd have to loop through every department, then every program, then every instructor, 
just to check one email. This is slow and repetitive — and it's exactly the problem normalization solves.

Now, in this and next couple steps, you should create a function `getInstructorByEmail` using loops on object,
which will take the a single argument email and retunn the name of the instructor.

To brgin with, declare a function `getInstructorByEmail` and return `null` from the function.
