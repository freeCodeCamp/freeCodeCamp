# --description--

At this point, `rawData` is deeply nested: `departments → programs → instructors`. To find an instructor by email, you would have to loop through each department, then each program, and finally each instructor until you find a match.

While that approach works, it becomes slow and repetitive as the data grows. 

Later on in the workshop, you will learn how to normalize the data which is a more efficient approach. 

But for the next few steps, you will create a function that takes an email as its argument, uses loops to search through the nested `rawData` structure, and returns the instructor's name when it finds a matching email address.

For now, firstly delete the `console.log()` of previous step.

Then, declare a function called `getInstructorByEmail` and use `email` for the parameter name. Then return `null` from the function.
