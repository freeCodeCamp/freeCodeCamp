# --description--

In this step, you will map out the structure you're working with. 
In `rawData`, multiple layers of data are nested within each other, following a hierarchy like this: `department → programs → instructors`.

At this point, `rawData` is deeply nested: `departments → programs → instructors`. To find an instructor by email, you would have to loop through each department, then each program, and finally each instructor until you find a match.

While that approach works, it becomes slow and repetitive as the data grows. 

Later on in the workshop, you will learn how to normalize the data which is a more efficient approach. 

But for the next few steps, you will create a function that takes an email as its argument, use loops to search through the nested `rawData` structure, and return the instructor's name when it finds a matching email address.


Declare a function called `getInstructorByEmail` and use `email` for the parameter name. Then return `null` from the function.
