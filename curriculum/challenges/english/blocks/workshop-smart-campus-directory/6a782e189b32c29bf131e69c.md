# --description--

Now you will loop through the departments in `rawData`. Use a `for...in` loop to 
iterate over the keys of `rawData`. Each key is a department name. 
Log the department name to the console inside the loop.

Here is a reminder on how to work with a `for...in` loop:

```js
const menu = {
  "Italian": { dishes: ["Pizza", "Pasta"] },
  "Mexican": { dishes: ["Tacos", "Burritos"] }
};

for (const cuisine in menu) {
  console.log(cuisine);
}
// "Italian"
// "Mexican"
```
