# --description--

To loop through `rawData`, you first need to convert it into something iterable. `Object.entries()` 
takes an object and returns an array of `[key, value]` pairs — one pair for each property.

Declare a variable called `departmentEntries` and set it to `Object.entries(rawData)`. 
Then log `departmentEntries` to the console to see the `[key, value]` pairs it produced.

```js
const rawData = {
  name: "Alice",
  age: 30
};

console.log(Object.entries(rawData));
/*
Output: 
[ ["name", "Alice"], ["age", 30] ]
*/
```
