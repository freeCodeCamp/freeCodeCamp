# --description--

In this step for each entry of departmentEntries, you will assign `departmentID` equals to `Dept_code`.  
Not every department is guaranteed to have a Dept_code. You need a fallback for when it's missing, so the department still gets a usable ID.

The || operator returns its left-hand value if that value is truthy, otherwise it returns the right-hand value. This makes it useful for defaults: a || b evaluates to a when a is truthy, and falls back to b when a is falsy (like undefined, null, or "").

```js
const code = undefined;
const fallback = code || "default-code";
console.log(fallback); // "default-code"
```

Now create variable `departmentId` equals to the `departmentData.Dept_code`, if `departmentData.Dept_code` is `undefined` take `dept-${i + 1}` as fallback.
