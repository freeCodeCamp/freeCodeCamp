# --description--

In Python, variables are names that refer to objects. Identity operators check whether two operands refer to the same object. The `is` operator returns `True` if they do, and `False` otherwise. The `is not` operator returns the opposite result.

Identity differs from equality: `==` and `!=` compare values, while `is` and `is not` compare object identity. Use equality operators when comparing number or string values.

Three objects you can check with identity operators are `None`, `True`, and `False`. Each is a singleton, meaning there is exactly one object for each.

## Checking for `None`

`None` represents the absence of a value. You can use `is None` to check whether a value is missing, or `is not None` to check whether it is present:

```python
response = None

print(response is None) # True
print(response is not None) # False
```

`None` is falsy, but it is not the same object as `False`. For example, a response could be `True` for yes, `False` for no, or `None` if no answer has been given:

```python
response = False

if response is None:
    print('No answer yet')
else:
    print('An answer was given') # An answer was given
```

Using `if not response` instead would treat both `False` and `None` alike. The identity check distinguishes a negative answer from a missing answer.

## Checking for `True` and `False`

You can also use identity to check specifically for the boolean objects:

```python
response = False

print(response is True) # False
print(response is False) # True
print(response is not None) # True
```

These checks ask whether `response` is exactly `True`, `False`, or an object other than `None`. They do not simply test truthiness.

For ordinary boolean flags, use direct truth tests such as `if is_ready` or `if not is_ready`. Use `is True` or `is False` when you specifically need to distinguish a boolean object from other possible values, as with a response that can also be `None`.
