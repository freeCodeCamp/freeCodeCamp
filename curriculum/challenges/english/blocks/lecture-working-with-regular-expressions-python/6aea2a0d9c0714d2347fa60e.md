# --description--

So far, you've used `re.search` to look for a pattern anywhere in a string. The `re` module has many other functions that work with regex patterns. In this lesson, you'll learn about some of the most useful ones.

## The `match` Function

The `match` function works like `search`, but it only looks for the pattern at the beginning of the string. It returns a match object if the start of the string matches the pattern, and `None` otherwise:

```python
import re

print(re.match(r'\d+', '42 apples'))
# <re.Match object; span=(0, 2), match='42'>

print(re.match(r'\d+', 'apples: 42')) # None
```

In the second example, the string contains digits, so `re.search` would find them. But the string doesn't start with digits, so `re.match` returns `None`.

## The `fullmatch` Function

The pattern `r'\d+:\d+'` matches one or more digits, followed by a colon and one or more digits. This is the shape of a time like `10:30`.

Imagine you want to check that some user input is a time, and nothing else. If you use `re.search`, you'll find a problem:

```python
import re

user_input = '10:30pm'
print(re.search(r'\d+:\d+', user_input))
# <re.Match object; span=(0, 5), match='10:30'>
```

This returns a match object, even though `10:30pm` doesn't follow the expected format. That's because `re.search` looks for the pattern anywhere in the string, and ignores any extra characters around the match. `re.match` would have the same problem, because `10:30pm` starts with a valid time.

When you are validating data, you usually want the whole string to follow the pattern. For that, you can use the `fullmatch` function. It returns a match object only when the pattern matches the entire string, and `None` otherwise:

```python
import re

print(re.fullmatch(r'\d+:\d+', '10:30pm')) # None

print(re.fullmatch(r'\d+:\d+', '10:30'))
# <re.Match object; span=(0, 5), match='10:30'>
```

## The `findall` Function

`search`, `match`, and `fullmatch` give you at most one match. When you want every match in a string, you can use the `findall` function. It returns a list of strings with all the matches it finds:

```python
import re

menu = 'Coffee costs 3 dollars, tea costs 2, and cake costs 5.'
print(re.findall(r'\d+', menu)) # ['3', '2', '5']
```

If there are no matches, `findall` returns an empty list:

```python
import re

print(re.findall(r'\d+', 'No numbers here')) # []
```

## The `sub` Function

The `sub` function replaces every match of a pattern with another string. It takes the pattern, the replacement string, and the string to search, and returns a new string:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message))
# My phone number is *** ****
```

`sub` also has two optional parameters. The first one is `count`, which limits how many matches get replaced:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message, count=3))
# My phone number is *** 0123
```

The second one is `flags`. Like the other functions, `sub` can use flags such as `re.IGNORECASE`:

```python
import re

sentence = 'Cat and cat'
print(re.sub('cat', 'dog', sentence, flags=re.IGNORECASE))
# dog and dog
```

Always pass `count` and `flags` as keyword arguments. If you pass `re.IGNORECASE` as the fourth positional argument, Python will treat it as the value of `count` instead.
