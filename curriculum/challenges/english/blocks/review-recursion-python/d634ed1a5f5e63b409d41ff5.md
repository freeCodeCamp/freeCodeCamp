# --description--

- **Recursion**: A technique in which a function calls itself. Each call works on a smaller version of the original problem until it reaches a base case that stops further recursive calls.
- **Base Case**: The condition that stops the recursion. You should carefully define the base case. Otherwise, the function can keep calling itself until Python raises a `RecursionError`.
- **Recursive Case**: The part of the function that calls the function again with an argument that moves it toward the base case, such as `number - 1` when counting down.

```py
def recursive_countdown(number):
    if number < 1:  # Base case
        return
    print(number)
    recursive_countdown(number - 1)  # Recursive case

recursive_countdown(5)  # Prints 5, 4, 3, 2, 1
```

- **Order of Execution**: The position of the recursive call changes when the function's other code runs. Code placed before the recursive call runs as the calls go deeper, while code placed after it runs as the calls return. Moving `print()` after the recursive call makes the function print the numbers in ascending order:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)  # Prints 1, 2, 3, 4, 5
```

- **Call Stack**: A last-in, first-out data structure that Python uses to keep track of active function calls. Each time a function is called, Python adds a frame for that call to the top of the stack. The frame contains information such as the function's arguments and local variables.
- **Resuming Calls**: A call pauses when it makes its recursive call. When the base case returns, Python removes that call from the top of the stack, and the earlier calls resume after their recursive call and return in last-in, first-out order:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

The output is:

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

- **Building a List Recursively**: Each call resumes when its recursive call returns, then uses the returned value. The `countup` function below returns an empty list in the base case. Each other call receives the list from its recursive call, appends its own number, and returns the list:

```py
def countup(number):
    if number < 1:
        return []
    count_list = countup(number - 1)
    count_list.append(number)
    return count_list

print(countup(5))  # [1, 2, 3, 4, 5]
```

The call with `1` receives `[]` and returns `[1]`, the call with `2` receives `[1]` and returns `[1, 2]`, and so on until the call with `5` returns `[1, 2, 3, 4, 5]`.

- **Applications of Recursion**: Recursion can handle simple tasks such as counting down, counting up, and building a list. It is also useful for problems with an unknown depth, such as traversing a file tree.
