## What Is Recursion?

- **Recursion**: A programming technique in which a function calls itself. Each call works on a smaller version of the original problem until it reaches a condition that stops the recursion.
- **Base Case**: The stopping condition in a recursive function. You should carefully define the base case so the function stops calling itself. Without a reachable base case, the function continues calling itself until Python raises a `RecursionError`.
- **Recursive Case**: The part of a recursive function that calls the function again with an argument that moves it toward the base case.
- **Applications of Recursion**: Recursive functions can perform simpler tasks such as counting, build and return data structures recursively, and solve problems with an unknown depth, such as traversing a file tree or deeply nested structures.

## The Call Stack and Execution Order

- **Call Stack**: A last-in, first-out (LIFO) data structure that Python uses to keep track of active function calls. When a function is called, Python adds a stack frame to the top of the stack containing information such as the function's arguments and local variables.
- **Execution Order**: When a function makes a recursive call, the current call pauses and remains on the call stack while the new call runs. Once the base case is reached and returns, the earlier suspended calls resume and return in last-in, first-out order. Placing an operation before versus after the recursive call changes the order of execution:

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)
    recursive_countdown(number - 1)

recursive_countdown(5)
```

In the above example, `print(number)` runs before each recursive call, printing `5`, `4`, `3`, `2`, and `1`. Placing `print(number)` after the recursive call reverses the order, printing `1`, `2`, `3`, `4`, and `5` as earlier calls resume after the base case returns:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)
```

- **Returning Values and Constructing Lists**: Recursive functions can return values to build data structures such as lists across successive calls. In this `countup` example, each call waits for the list returned by the recursive call, appends the current number, and returns the accumulated list:

```py
def countup(number):
    if number < 1:
        return []
    count_list = countup(number - 1)
    count_list.append(number)
    return count_list

print(countup(3)) # Output: [1, 2, 3]
```
